「親が亡くなってからもう半年以上経つのに、突然借金の請求書が届いた」「相続放棄の期限が3ヶ月だと知らなかった」。こうしたご相談は珍しくありません。

相続放棄の期限は原則3ヶ月です。しかし、期限を過ぎたからといって全てのケースで手遅れになるわけではありません。最高裁判所の判例により、一定の条件を満たせば期限後でも相続放棄が認められる可能性があります。

この記事では、相続放棄の3ヶ月ルールの基本から、期限切れ後に取れる対処法、あなたのケースで相続放棄が認められるかどうかの判定フローチャート、そして専門家に相談すべきケースまで解説します。

相続放棄の3ヶ月ルール（熟慮期間）とは

民法915条の基本ルール

相続放棄ができる期間は、民法915条で「自己のために相続の開始があったことを知った時から3ヶ月以内」と定められています。この3ヶ月間を「熟慮期間」と呼びます。

ここで重要なのは、「知った時」の解釈です。起算点は「被相続人が亡くなった日」ではなく、以下のいずれかです。

  • 被相続人の死亡を知り、自分が相続人であることを認識した日
  • 先順位の相続人全員が放棄したことで自分が相続人になったことを知った日
  • 遺言により自分が相続人に指定されたことを知った日

たとえば、疎遠だった父親が1月に亡くなっていたことを4月に初めて知った場合、起算点は4月です。1月から3ヶ月が経過していても、まだ熟慮期間内ということになります。

3ヶ月を過ぎるとどうなるか

熟慮期間の3ヶ月以内に相続放棄も限定承認もしなかった場合、「単純承認」をしたものとみなされます（民法921条2号）。

単純承認とは、被相続人のプラスの財産（預金・不動産など）もマイナスの財産（借金・未払い税金など）もすべて引き継ぐことを意味します。つまり、借金が財産を上回っていれば、その差額を自分の財産から返済する義務を負うことになります。

単純承認とみなされる行為にも注意

3ヶ月以内であっても、以下の行為をすると単純承認とみなされ、相続放棄ができなくなります。

  • 相続財産の処分: 被相続人の不動産を売却した、預金を引き出して自分のために使った
  • 相続財産の隠匿・消費: 相続財産を隠したり、わざと使い込んだりした
  • 相続財産の名義変更: 不動産の相続登記を自分名義で完了させた

ただし、葬儀費用の支払いや、形見分け程度の少額の品物の持ち帰りは、通常は単純承認にはあたりません。

あなたの場合はまだ間に合う？判定フローチャート

以下のフローチャートで、あなたのケースで相続放棄の可能性があるかどうかを確認してみてください。

ステップ1. 相続の開始を知ってから3ヶ月以内ですか？

はい → 通常の相続放棄が可能です。家庭裁判所に相続放棄の申述をしてください。

いいえ → ステップ2へ

ステップ2. 相続財産（特に借金）の処分行為をしましたか？

以下のいずれかに該当する場合、相続放棄は原則として認められません。

  • 被相続人の不動産を売却・名義変更した
  • 被相続人の預金を自分のために引き出して使った
  • 被相続人の財産を隠したり、意図的に財産目録に記載しなかった

該当する → 相続放棄は困難です。弁護士に相談してください。

該当しない → ステップ3へ

ステップ3. 3ヶ月以内に判断できなかった理由は何ですか？

以下のいずれかに該当する場合、期限後でも相続放棄が認められる可能性があります。

  • 被相続人に借金があることを全く知らなかった
  • 被相続人と疎遠で、財産や生活状況を把握できなかった
  • 相続財産が全くないと信じる相当な理由があった（生活保護受給中だった等）
  • 後になって初めて借金の存在を知った（債権者からの通知等）

該当する → 弁護士に相談し、期限後の相続放棄申述を検討してください。

該当しない → 相続放棄は難しい可能性が高いです。ステップ4へ

ステップ4. 相続放棄以外の対処法を検討する

相続放棄が難しい場合でも、以下の対処法があります。

  • 不動産を売却して借金を返済する
  • 債権者と交渉して返済条件を見直す（任意整理）
  • 自己破産を検討する

いずれの場合も、早めに弁護士に相談することが最善の選択肢です。

期限後でも相続放棄が認められる3つのケース

ケース1. 借金の存在を後から知った場合

最も多いパターンです。最高裁昭和59年4月27日判決は、以下の条件をすべて満たす場合に、熟慮期間の起算点を遅らせることを認めました。

  1. 3ヶ月以内に相続放棄をしなかったのは、被相続人に相続財産が全くないと信じたためであること
  2. 被相続人の生活歴、被相続人と相続人との交際状態その他諸般の状況から、相続財産の有無の調査を期待することが著しく困難な事情があること
  3. 相続人が相続財産の不存在を信じたことについて相当な理由があること

この判例によれば、借金の存在を知った日が新たな起算点となり、そこから3ヶ月以内であれば相続放棄が認められる可能性があります。

認められやすい具体的な事情

  • 被相続人と長期間（10年以上など）交流がなかった
  • 被相続人が生活保護を受けていた
  • 被相続人の死亡後に遺産を調べたが、財産が見つからなかった
  • 他の相続人からも借金の話を聞いていなかった

ケース2. 先順位の相続人が放棄したことを知らなかった場合

被相続人の子（第1順位）が全員相続放棄をした場合、次順位の親や兄弟姉妹が相続人になります。

しかし、家庭裁判所から次順位の相続人に自動的に通知が届くわけではありません。子が相続放棄をした事実を知らないまま、気づいた時には3ヶ月以上経過していたというケースがあります。

この場合、「自分が相続人になったことを知った日」が起算点になるため、その日から3ヶ月以内であれば相続放棄が可能です。

ケース3. 熟慮期間の伸長を申し立てていた場合

3ヶ月の期限内に家庭裁判所へ「相続の承認又は放棄の期間の伸長」を申し立てることで、熟慮期間を延長できます。

伸長が認められやすい事情

  • 相続財産が多岐にわたり調査に時間がかかる
  • 相続人が多数いて意思確認に時間を要する
  • 被相続人の事業に関する債務の調査が必要
  • 遠方に住んでいて現地調査が困難

伸長が認められる期間は、通常1〜3ヶ月です。再度の伸長申立ても認められる場合があります。

申立てに必要なもの

必要書類備考
申立書裁判所ウェブサイトからダウンロード可
被相続人の住民票除票（または戸籍附票）最後の住所地を確認するため
被相続人の死亡が記載された戸籍謄本—
申立人の戸籍謄本相続人であることの証明
収入印紙800円相続人1人につき800円
連絡用の郵便切手金額は裁判所により異なる

申立先は、被相続人の最後の住所地を管轄する家庭裁判所です。

期限切れの相続放棄を成功させるためのポイント

ポイント1. 借金を知った日の証拠を残す

期限後の相続放棄を認めてもらうには、「いつ借金の存在を知ったか」を証明する必要があります。以下の書類は必ず保管してください。

  • 債権者からの督促状や通知書（届いた日がわかる封筒ごと保管）
  • 信用情報機関への照会結果
  • 他の相続人とのやり取り（メール・LINE等のスクリーンショット）

ポイント2. 知った日から速やかに行動する

借金の存在を知ってから3ヶ月以内に相続放棄の申述をする必要があります。「もう少し調べてから」と先延ばしにするのは危険です。

借金の通知を受け取ったら、1週間以内に弁護士に相談することをおすすめします。

ポイント3. 相続財産に手を付けない

借金の通知を受け取った後に被相続人の財産を処分してしまうと、単純承認とみなされるおそれがあります。

  • 被相続人名義の預金を引き出さない
  • 被相続人名義の不動産の名義変更をしない
  • 被相続人の債務を自分の財産から返済しない

ポイント4. 弁護士に依頼する

通常の相続放棄（期限内）であれば司法書士でも対応できますが、期限後の相続放棄は弁護士に依頼することを強くおすすめします。

期限後の相続放棄では、家庭裁判所に対して「なぜ3ヶ月以内に放棄できなかったのか」を法的に説得力のある形で説明する必要があります。上申書の作成や証拠の整理は、相続に詳しい弁護士の力を借りたほうが確実です。

相続放棄ができない場合の不動産の出口戦略

相続放棄の期限が過ぎていて、かつ期限後の放棄も認められない場合、相続した不動産を売却して借金の返済に充てる方法があります。

訳あり不動産でも売却できるケースは多い

以下のような不動産でも、買取業者であれば対応できる場合があります。

  • 築年数が古く老朽化が進んでいる物件
  • 再建築不可物件
  • 相続登記が済んでいない物件（登記完了を条件に買取可能）
  • 共有名義の物件（持分のみの売却も可能）
  • 残置物が残ったままの物件

一般的な仲介では買い手がつきにくい物件でも、訳あり物件専門の買取業者であれば現状のまま・短期間で買い取ることができます。

売却資金で借金を返済する流れ

  1. 相続登記を完了させる（未了の場合）
  2. 訳あり物件対応の買取業者に査定を依頼する
  3. 買取金額に合意したら売買契約を締結する
  4. 売却代金から借金を返済する
  5. 残余金があれば手元に残る

借金の総額が不動産の売却額を上回る場合は、弁護士と相談のうえ任意整理や自己破産を検討することも選択肢の一つです。

専門家に相談すべき5つのケース

以下のいずれかに該当する場合は、自分だけで判断せず、必ず専門家に相談してください。

  1. 3ヶ月の期限を過ぎてから借金の存在を知った → 弁護士に相談（期限後の相続放棄の可否を判断）
  2. 被相続人の財産に手を付けてしまった可能性がある → 弁護士に相談（単純承認に該当するか判断）
  3. 相続人が複数いて意見がまとまらない → 弁護士に相談（遺産分割協議の調整）
  4. 相続した不動産の売却方法がわからない → 宅建業者に相談（訳あり物件の買取対応）
  5. 借金の額が不動産の価値を上回っている → 弁護士に相談（債務整理の方法を検討）
