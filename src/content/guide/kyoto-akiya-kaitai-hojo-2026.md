## 京都市で空き家・実家を放置すると、毎年これだけかかる

まず、決めずに放置した場合に何が起きるかを確認します。空き家は「置いておくだけ」でも毎年お金が出ていきます。

- <strong>固定資産税・都市計画税</strong>：建物と土地に毎年かかります。住宅が建っている土地は「住宅用地の特例」で税額が軽くなっていますが、これは建物があることが前提です。
- <strong>草刈り・害虫・ゴミの対応</strong>：放置すると雑草や害虫が発生し、近隣とのトラブルにつながります。
- <strong>雨漏り・外壁の劣化</strong>：木造は特に傷みが早く、放置期間が延びるほど修繕や解体の費用がかさみます。

さらに見落としがちなのが、<strong>「特定空家」に指定されると税負担が跳ね上がる</strong>点です。空家等対策特別措置法にもとづき、市から「特定空家」や「管理不全空き家」に指定されて勧告を受けると、<strong>住宅用地の特例が外れて固定資産税が最大で約6倍になる</strong>ことがあります。倒壊のおそれや衛生上の問題があると判断された建物が対象です。

> **宅建業者の視点**: 京都市は袋路（路地の奥）や狭い敷地に建つ古い木造住宅が多く、「隣に迷惑をかけないうちに何とかしたい」というご相談をよくいただきます。迷っている時間そのものにコストがかかっている、とお伝えしています。

つまり、京都市の空き家は「解体するか」「そのまま手放すか」を早く決めるほど、出ていくお金を抑えられます。

## 京都市の解体補助金①：空き家等の活用・流通（敷地活用）補助金

京都市には、狭小敷地に建つ空き家を解体して敷地の活用を促す<strong>「京都市空き家等の活用・流通（敷地活用）補助金」</strong>があります。解体除却工事の費用の一部を補助する制度です。

<img src="/images/kyoto-akiya-kaitai-hojo-2026-hojokin.jpg" alt="電卓と書類で解体費用と補助金額を試算する様子。京都市の空き家解体補助金のイメージ" width="1200" height="800" loading="lazy" />

| 項目 | 内容 |
|------|------|
| 補助の対象工事 | 空き家の解体除却工事（原則、敷地全体を更地にするもの） |
| 対象となる空き家 | 昭和64年1月7日以前に建築された建築物（<strong>京町家を除く</strong>）／個人が所有 |
| 敷地の条件 | 敷地面積が<strong>50平方メートル以下</strong> |
| 補助額 | 「解体除却工事費用」と「延床面積(㎡)×<strong>32,000円</strong>」の<strong>いずれか低い額 × 1/3</strong>（<strong>上限60万円</strong>） |
| 令和8年度の受付 | 令和8年4月1日（水曜日）から受付開始 |
| 問い合わせ | 京都市空き家相談窓口（075-231-2323） |

たとえば延床面積60㎡・解体除却工事費用が150万円の空き家の場合、「延床面積×32,000円」は192万円、実際の工事費は150万円なので、低いほうの150万円が基準になります。その3分の1は50万円で上限60万円以内に収まるため、この金額が補助の目安になります。工事費が大きくても、受け取れるのは上限の60万円までです。

なお、この補助金にはもう1つ<strong>「建物活用補助」</strong>というメニューもあり、空き家を売却した元所有者が<strong>京都市内に主たる事務所を置く不動産事業者</strong>に支払った仲介手数料の一部（<strong>2分の1・上限25万円</strong>）を補助する仕組みです。解体ではなく「そのまま売る」ときに関係する補助です。

*（出典: 京都市公式サイト「京都市空き家等の活用・流通（敷地活用）補助金」「同（建物活用）補助金」2026年時点。予算がなくなり次第受付終了。予算枠・要件は年度途中で変わるため必ず窓口で最新確認）*

## 京都市の解体補助金②：老朽木造建築物除却事業（防災まちづくり）

京都市には、防災上の課題がある区域の古い木造建築物を取り壊す費用を補助する<strong>「老朽木造建築物除却事業」</strong>もあります。防災まちづくり推進事業の一環で、袋路（路地奥）や狭い道路にしか接していない旧耐震の木造住宅などが対象です。

| 項目 | 内容 |
|------|------|
| 対象建物 | <strong>昭和56年5月31日以前</strong>の旧耐震基準で建築された木造建築物（<strong>京町家を除く</strong>） |
| 立地の条件 | 袋路のみに接する、または幅員1.8メートル未満の道路のみに接するなど（複数条件のいずれか） |
| 対象区域 | 市が定める<strong>対象区域内</strong>（優先地区として柏野・翔鸞・仁和・正親・出水・六原の各学区が示されています） |
| 補助額 | 除却費用の<strong>2分の1（上限60万円）</strong> |
| 申請のタイミング | 交付申請 → 交付決定通知の受取 → <strong>その後に工事契約</strong>（契約・着工前の申請が必須） |
| 問い合わせ | 京都市都市計画局 まち再生・創造推進室（075-222-3503） |

この制度は「耐震性が低く、災害時に道をふさぐおそれのある古い木造建築物」を減らすことが目的のため、<strong>建物の築年（旧耐震）だけでなく、建っている場所（区域・接道）が条件になる</strong>点が特徴です。ご自身の空き家が対象になるかは、住所と接道状況をもとに市の窓口で確認するのが確実です。

*（出典: 京都市公式サイト「防災まちづくり推進事業（老朽木造建築物除却事業）」2026年時点。補助金は予算がなくなり次第受付終了。区域・要件・予算枠は年度途中で変わるため必ず窓口で最新確認）*

## 補助金を使う前に知っておきたい4つの落とし穴

補助金は魅力的ですが、誰でも・いつでも使えるわけではありません。ご相談の際によくお伝えする4つの注意点です。

1. <strong>建物・敷地・区域の条件が細かい</strong>：敷地活用補助は「敷地50㎡以下・京町家を除く」、老朽木造建築物除却事業は「対象区域内・袋路など接道条件」があります。京町家は原則これらの解体補助の対象外です。条件を満たすかは自己判断せず、必ず窓口で確認してください。
2. <strong>契約・着工の前に申請が必要</strong>：先に解体業者と契約したり工事を始めたりすると、補助金は一切受け取れません。「もう壊してしまった」後では手遅れです。
3. <strong>予算がなくなり次第、受付終了</strong>：京都市の補助金は年度ごとに予算枠があり、<strong>枠が埋まるとその年度の受付は終了</strong>します。令和8年度は令和8年4月1日から受付開始ですが、早い時期に埋まることもあります。<strong>予算枠は年度途中で変わるため、必ず窓口で最新の状況を確認してください。</strong>
4. <strong>あくまで費用の一部・自己負担が残る</strong>：補助は解体費の一部（1/3または1/2・上限60万円）です。工事費が150万円なら、少なくとも90万円前後は自己負担で用意する必要があります。

> **宅建業者の視点**: 「補助金が出るなら解体しよう」と考えて業者に見積もりを取り、そのまま契約してから相談に来られる方がいます。契約後では補助金が使えないため、<strong>補助金を使うつもりなら、動く前に必ず市の窓口へ先に相談する</strong>ことが大切です。

## 補助金だけでは解決しないケース｜「解体して更地」か「古家付きで買取」か

補助金を使えば解体費の一部は戻りますが、それでも<strong>数十万円〜100万円以上の自己負担</strong>と、申請から工事完了まで数ヶ月の時間がかかります。しかも更地にすると住宅用地の特例が外れ、翌年からの土地の固定資産税は上がります。

そこで比べていただきたいのが、「補助金を使って解体し更地で売る」場合と、「<strong>古家付き（現況）のまま買い取ってもらう</strong>」場合です。

| 選択肢 | 解体費の負担 | 手放すまでの期間 | 向いている人 |
|--------|------------|----------------|-------------|
| 補助金を使って解体→更地で売る | 自己負担あり（補助は1/3〜1/2・上限60万円） | 申請〜工事〜売却で数ヶ月 | 条件・区域を満たし、時間に余裕がある |
| 古家付き（現況）のまま買取 | <strong>不要</strong>（解体せず売る） | 最短で現金化できるケースあり | 早く手放したい・条件を満たさない・解体費を出したくない |

古家付きのまま売る場合、<strong>解体費を自分で払う必要がなく、補助金の申請手続きも不要</strong>です。訳あり物件を専門に扱う買取であれば、旧耐震・再建築不可・傾きや雨漏りのある家でも、現況のまま買い取れる場合があります。残置物（家財）が残っていても、そのままで査定できるケースもあります。

「更地にした方が高く売れるのか」「古家付きのまま売った方が手元に多く残るのか」は、立地と建物の状態で変わります。<strong>どちらが手取りで有利かは、両方を見積もって比べるのが確実です。</strong>

## 京都市で「手放したい」を選んだら：進め方3ステップ

<img src="/images/kyoto-akiya-kaitai-hojo-2026-soudan.jpg" alt="相続した京都市の実家の売却について専門家に相談する様子。空き家の査定相談のイメージ" width="1200" height="800" loading="lazy" />

補助金を使って解体するにせよ、古家付きで売るにせよ、最初にやることは同じです。<strong>「今いくらで手放せるか」を知ること</strong>です。

1. <strong>今の買取額を確認する</strong>：所在地（京都市内のエリア）・築年数・建物の状態を伝えれば、無料で概算をお出しできます。解体前・片づけ前でも大丈夫です。
2. <strong>現況のまま査定を受ける</strong>：リフォームや残置物の片づけは不要です。旧耐震・再建築不可・傷みのある家でも、そのまま査定できる場合があります。
3. <strong>補助金を使った解体と比べて決める</strong>：更地にして売った場合と、古家付きで買い取った場合の手取りと期間を比べて、納得できる方をお選びいただけます。補助金の対象になるかどうか（区域・敷地・築年）は、並行して市の窓口で確認しておくと安心です。

補助金の申請中は着工できないため、<strong>「補助金を使った解体」と「早期の現況買取」は同時並行が難しい</strong>場合があります。だからこそ、まず両方の見込みを並べて比べることをおすすめします。

## まとめ：京都市の空き家は「補助金」と「現況買取」を並べて比べる

京都市で相続した空き家・実家を手放したいときの整理です。

- 京都市には解体補助が主に2つ。<strong>敷地活用補助</strong>（工事費と延床×32,000円の低い額の1/3・上限60万円／敷地50㎡以下・京町家を除く）と、<strong>老朽木造建築物除却事業</strong>（補助率1/2・上限60万円／対象区域内・旧耐震・袋路など）。
- どちらも<strong>契約・着工前の申請が必須</strong>で、京町家や条件・区域を満たさない建物は対象外。<strong>予算がなくなり次第受付終了</strong>のため、必ず窓口で最新の予算枠と要件を確認する。
- 補助金を使っても<strong>自己負担と数ヶ月の時間</strong>がかかり、更地にすると土地の固定資産税は上がる。

- どちらが手取りで有利かは、<strong>両方を見積もって比べる</strong>のが確実。

決めずに放置すると、固定資産税と管理費を払い続けながら、建物の傷みで手放す条件も悪くなっていきます。まずは「今いくらで手放せるか」を確認することが、いちばん確実な最初の一歩です。査定は無料です。
