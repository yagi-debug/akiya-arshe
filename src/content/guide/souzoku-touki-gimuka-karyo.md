相続した不動産の名義変更（相続登記）を済ませていない方は、今すぐ確認してください。<strong>2024年4月から相続登記が義務化</strong>され、正当な理由なく放置すると<strong>10万円以下の過料</strong>が科される可能性があります。

さらに、登記を放置したまま空き家になった不動産は、自治体から<strong>「特定空き家」</strong>に指定されるリスクがあります。指定されると固定資産税の軽減措置が解除され、<strong>税負担が最大6倍</strong>に膨れ上がります。

つまり、相続登記を放置すると<strong>「過料」と「固定資産税の増額」という二重のペナルティ</strong>を受ける可能性があるということです。

この記事では、過料が科されるまでの具体的なプロセス、2027年3月の経過措置期限、そして売却によってこれらのリスクを一括で解消する方法を解説します。

## 相続登記の義務化とは？2024年4月からの変更点

### 義務化の背景

これまで相続登記は任意でした。「手続きが面倒」「費用がかかる」「誰が相続するか決まっていない」などの理由で放置されるケースが非常に多く、全国で<strong>所有者不明の土地が国土の約24%</strong>にまで拡大していました。

この深刻な問題を解消するため、不動産登記法が改正され、<strong>2024年4月1日から相続登記が義務化</strong>されました。

### 義務化の具体的なルール

| 項目 | 内容 |
|------|------|
| 施行日 | 2024年4月1日 |
| 対象 | 相続で不動産を取得したすべての人 |
| 期限 | 相続の開始と不動産の取得を<strong>知った日から3年以内</strong> |
| 罰則 | 正当な理由なく怠った場合、<strong>10万円以下の過料</strong> |
| 過去の相続 | <strong>対象</strong>（経過措置で2027年3月31日が期限） |

ここで重要なのは、<strong>2024年4月より前に発生した相続も対象</strong>という点です。10年前、20年前に親が亡くなり、名義変更をしていない不動産がある方も義務の対象になっています。

## 過料10万円が科されるまでの具体的なプロセス

「10万円以下の過料」と聞くと不安になりますが、期限を過ぎた翌日にいきなり請求されるわけではありません。過料が科されるまでには、以下のプロセスがあります。

<img src="/images/souzoku-touki-gimuka-tax-calculation.jpg" alt="電卓と書類　過料や税負担を計算するイメージ" width="1200" height="689" style="width:100%;height:auto;border-radius:8px;margin-bottom:1.5rem;" />

### ステップ1：法務局が未登記を発見

法務局（登記官）が、相続登記がされていない不動産を発見します。固定資産税の課税情報や死亡届の情報などがきっかけになります。

### ステップ2：催告（登記するよう通知）

法務局から相続人に対し、<strong>相続登記を行うよう催告（通知）</strong>が届きます。この段階ではまだ過料は発生しません。

### ステップ3：それでも放置した場合

催告を受けたにもかかわらず、<strong>正当な理由なく登記申請を行わない場合</strong>、法務局が裁判所にその旨を通知します。

### ステップ4：裁判所が過料を決定

通知を受けた裁判所が、相続人から事情を聴取したうえで、過料を科すかどうか、またその金額（10万円の範囲内）を決定します。

### 「正当な理由」として認められるケース

以下のような事情がある場合は、「正当な理由」として過料の対象外となる可能性があります。

- 相続人が極めて多数で戸籍関係書類の収集に時間がかかる
- 遺言の有効性や遺産の範囲について相続人間で争いがある
- 本人が重病やその他これに準ずる事情がある
- DV被害者で生命・心身に危害が及ぶおそれがある
- 経済的に困窮しており登記費用を負担する能力がない

ただし、「忙しかった」「知らなかった」といった理由は、正当な理由として認められにくいと考えられます。

## 2027年3月31日の期限に要注意

### 過去の相続に適用される経過措置

2024年4月1日より前に発生した相続についても、義務化の対象です。ただし経過措置として、<strong>2027年3月31日まで</strong>に相続登記を済ませれば過料の対象にはなりません。

この期限まで、残り<strong>約1年</strong>です。

### 期限を過ぎるとどうなるか

| 状況 | リスク |
|------|--------|
| 2027年3月31日までに登記完了 | 過料なし |
| 期限を過ぎて催告に応じた | 過料の可能性は低い |
| 催告を無視し続けた | <strong>10万円以下の過料</strong> |
| さらに空き家化 | 過料＋<strong>固定資産税が最大6倍</strong> |

特に注意が必要なのは、登記を放置したまま不動産が空き家になるケースです。次の章で詳しく解説します。

## 放置すると二重ペナルティ：過料＋固定資産税6倍

相続登記をしないまま不動産を放置すると、以下の二重のリスクが発生します。

### リスク1：過料（10万円以下）

前述のとおり、正当な理由なく相続登記を怠ると10万円以下の過料が科される可能性があります。

### リスク2：特定空き家・管理不全空き家による固定資産税の増額

2023年12月の空き家対策特別措置法の改正により、<strong>「管理不全空き家」</strong>という新しいカテゴリが加わりました。特定空き家の一歩手前の状態（窓ガラスの破損、雑草の繁茂など）でも、勧告を受けると<strong>住宅用地の特例が解除</strong>されます。

| 指定状況 | 固定資産税への影響 |
|---------|-----------------|
| 通常の住宅用地 | 最大<strong>6分の1に軽減</strong> |
| 管理不全空き家（勧告後） | 軽減措置<strong>解除</strong> |
| 特定空き家（勧告後） | 軽減措置<strong>解除</strong> |

### 具体的な金額で見る二重ペナルティ

土地200平米、固定資産税評価額1,500万円の不動産を例に計算します。

<strong>通常の場合（特例あり）</strong>
- 固定資産税：1,500万円 × 1/6 × 1.4% = 約3.5万円/年

<strong>特定空き家に指定された場合（特例なし）</strong>
- 固定資産税：1,500万円 × 1.4% = 約21万円/年

差額は<strong>年間約17.5万円</strong>。これに過料（最大10万円）が加わると、<strong>初年度だけで最大約27.5万円の負担増</strong>になります。しかも固定資産税の増額は指定が解除されるまで毎年続きます。

## 間に合わない場合の救済策：相続人申告登記

遺産分割協議がまとまらず期限に間に合わない場合でも、過料を回避する方法があります。

### 相続人申告登記とは

2024年4月に新設された制度で、<strong>「私がこの不動産の相続人の一人です」</strong>と法務局に申し出る手続きです。

| 項目 | 内容 |
|------|------|
| 申請者 | 相続人のうち<strong>1人でも単独で可能</strong> |
| 費用 | <strong>登録免許税なし</strong>（実質無料） |
| 必要書類 | 申出書、自身の戸籍謄本など（被相続人の出生〜死亡の連続戸籍は不要） |
| 効果 | <strong>暫定的に登記義務を履行したとみなされる</strong> |

通常の相続登記と比べて手続きが簡単で、費用もほぼかかりません。遺産分割がまとまるまでの時間稼ぎとして有効な制度です。

### 注意点

相続人申告登記はあくまで<strong>暫定措置</strong>です。遺産分割が成立したら、<strong>その日から3年以内に正式な相続登記</strong>を行う必要があります。また、相続人申告登記だけでは不動産を売却することはできません。

## 売却すれば過料リスクも固定資産税も一括解消

<img src="/images/souzoku-touki-gimuka-consultation.jpg" alt="不動産の売却相談をしている場面のイメージ" width="1200" height="801" style="width:100%;height:auto;border-radius:8px;margin-bottom:1.5rem;" />

相続登記の過料リスク、固定資産税の増額リスク、空き家の管理負担。これらを<strong>まとめて解消する方法が「売却」</strong>です。

### 売却で解消できること

- <strong>相続登記の義務</strong>：売却にあたって相続登記を行うため、義務を果たしたことになる
- <strong>固定資産税の負担</strong>：所有権が買主に移転するため、翌年度から課税されなくなる
- <strong>空き家の管理責任</strong>：所有者でなくなるため、管理義務から解放される
- <strong>特定空き家のリスク</strong>：そもそも所有していないので指定の対象外

### 「登記をしていないから売れない」は誤解

相続登記が済んでいない不動産でも、<strong>買取業者であれば対応可能</strong>です。売買の流れは以下のとおりです。

1. 買取業者に相談（現状のまま相談OK）
2. 査定・買取価格の提示
3. 相続登記の手続き（司法書士が代行）
4. 売買契約の締結
5. 決済・引き渡し

登記手続きを含めたスケジュール調整や、司法書士の手配まで買取業者がサポートするケースが一般的です。相続登記の費用も、売却代金から充当できます。

### 2027年3月の期限前に動くべき理由

経過措置の期限（2027年3月31日）が近づくにつれて、同じような状況の相続人が一斉に動き始めることが予想されます。

- 司法書士への依頼が集中し、<strong>手続きに時間がかかる可能性</strong>
- 売却希望者が増えることで、<strong>買取価格に影響</strong>が出る可能性
- 法務局の処理も混み合い、<strong>登記完了までの期間が長引く可能性</strong>

早めに動くことで、これらのリスクを避けられます。

## 相続登記の放置が売却価格に与える影響

相続登記をしていない期間が長くなるほど、売却のハードルが上がるケースがあります。

### 数次相続の発生

相続登記をしないまま相続人が亡くなると、<strong>さらにその相続人に権利が引き継がれます</strong>（数次相続）。関係者が増えるほど遺産分割協議が難航し、全員の同意を得るまでに時間と費用がかかります。

### 物件の劣化

建物は人が住まなくなると急速に劣化します。換気がされない、水道を使わない、小さな破損を放置するといった状態が続くと、<strong>建物の価値が大きく下がります</strong>。

### まとめ：放置期間が長いほど損をする

| 放置期間 | 起こりうる問題 |
|---------|-------------|
| 1〜2年 | 建物の軽微な劣化、庭の雑草繁茂 |
| 3〜5年 | 管理不全空き家に指定されるリスク、近隣トラブル |
| 5〜10年 | 数次相続の発生、特定空き家の指定、大幅な価値下落 |
| 10年以上 | 関係者が多数になり売却が極めて困難に |

早期に売却することで、<strong>物件の価値が保たれているうちに適正な価格で手放す</strong>ことができます。

## よくある質問

<strong>Q. 相続登記にはいくらかかりますか？</strong>

登録免許税（固定資産税評価額の0.4%）と、司法書士への報酬（5〜10万円程度）が主な費用です。固定資産税評価額が1,000万円の不動産であれば、登録免許税は4万円。合計で10〜15万円程度が目安になります。

<strong>Q. 相続人全員の同意が得られない場合はどうすればいいですか？</strong>

遺産分割協議がまとまらない場合、まず相続人申告登記で過料リスクを回避してください。そのうえで、家庭裁判所の調停を利用する方法があります。共有持分のみを売却することも選択肢の一つです。

<strong>Q. 遠方に住んでいて管理できない不動産はどうすればいいですか？</strong>

遠方の不動産こそ早期売却をおすすめします。管理のために通う交通費・管理委託費・固定資産税を合計すると、年間数十万円の出費になるケースも珍しくありません。買取であれば、現地に行かずに手続きを進められます。
