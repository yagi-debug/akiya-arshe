## 名古屋市の空き家解体補助金は3つある｜まず自分がどれに当たるかを見分ける

最初にやるべきことは、金額を調べることではなく、<strong>自分の空き家がどの制度の土俵に乗っているかを見分けること</strong>です。3制度は「何を減らしたい制度か」がそれぞれ違い、見ている条件も違います。

- <strong>①老朽危険空家等除却費補助金</strong>：<strong>周辺に危険を及ぼしている「特定空家等」を減らす</strong>ための制度。見ているのは「市が特定空家等と判断したか」と「老朽危険度の点数」です。
- <strong>②戸建木造住宅除却助成</strong>：<strong>地震で倒れるおそれのある旧耐震の戸建木造住宅を減らす</strong>ための制度。見ているのは「昭和56年5月31日以前の着工か」と「耐震診断の判定値」です。
- <strong>③老朽木造住宅除却助成</strong>：<strong>木造住宅が密集した地域の防災性を上げる</strong>ための制度。見ているのは「木造住宅密集地域にあるか」です。

つまり、同じ「古い空き家」でも、<strong>危険度で見られるのか、耐震性で見られるのか、場所で見られるのか</strong>が制度ごとに違います。ここを取り違えると、電話をかけた窓口で「うちの担当ではありません」と言われ、また最初から調べ直すことになります。

## 【制度①】名古屋市老朽危険空家等除却費補助金｜最大80万円・「特定空家等」が前提

名古屋市でもっとも補助額が大きいのが<strong>「名古屋市老朽危険空家等除却費補助金」</strong>です。腐朽・破損が著しく、周辺に保安上の危険を及ぼしている空き家の除却が対象です。

| 項目 | 内容 |
|------|------|
| 対象となる建築物 | 法及び条例に規定する<strong>「特定空家等」として市が判断した建築物</strong> |
| 対象者 | その建築物の<strong>所有者（法人は対象外）</strong>／<strong>所有者全員の同意</strong>を得て補助事業を行う者／<strong>市税の滞納がない</strong>こと |
| 補助額（評価75点以上） | 除却に要する経費の<strong>3分の1（最大40万円）</strong> |
| 補助額（評価125点以上） | 除却に要する経費の<strong>3分の2（最大80万円）</strong> |
| 対象工事費の考え方 | <strong>国の定める標準除却工事費</strong>に基づく |

| 受付 | <strong>先着</strong>での受付。<strong>予算額に達し次第、受付終了</strong> |
| 完了期限 | 交付決定があった日の属する年度の<strong>2月末日まで</strong>に工事完了と書類提出等すべての手続きを完了 |
| 問い合わせ | スポーツ市民局 地域振興部 地域振興課（052-972-3126） |

補助額は「老朽危険空家等の評価」表による点数で2段階に分かれます。<strong>75点以上で3分の1（最大40万円）、125点以上で3分の2（最大80万円）</strong>です。危険度が高いほど手厚くなる設計です。

ここでいちばん重要なのは、<strong>「市が特定空家等と判断していること」が入口条件</strong>だという点です。単に古い、単に使っていない、というだけでは対象になりません。逆に言えば、市から助言・指導や勧告の通知が届いている空き家をお持ちの方は、<strong>この制度に当たる可能性がある</strong>ということです。通知を「怖いもの」として引き出しにしまい込んでいる方がいらっしゃいますが、その通知は補助の入口になり得る書類です。

## 「延床面積×9,600円」の意味を誤解しない｜補助額の計算例

制度②③の助成額に出てくる<strong>「1平方メートルあたり9,600円」</strong>という数字は、多くの方が誤解するポイントです。これは<strong>助成額を計算するための単価</strong>であって、<strong>実際の解体工事がこの単価で収まるという意味ではありません</strong>。

<img src="/images/nagoya-akiya-kaitai-hojo-2026-hojokin.jpg" alt="電卓と書類を前に解体費用と補助金額を計算する様子。名古屋市の解体補助金の試算イメージ" width="1200" height="800" loading="lazy" />

実際に計算してみます。

<strong>例1：延床100㎡の戸建木造住宅、解体費用の見積もりが150万円（制度②）</strong>

- 上限額 …… 200,000円
- 除却費用の1/3 …… 1,500,000 ÷ 3 ＝ 500,000円
- 延床面積×9,600円の1/3 …… 100 × 9,600 ＝ 960,000円 → ÷3 ＝ 320,000円

3つのうち<strong>最も低い額</strong>なので、助成額は<strong>200,000円</strong>。見積もり150万円に対して、自己負担は130万円です。

<strong>例2：延床50㎡の小さな平屋、解体費用の見積もりが90万円（制度②）</strong>

- 上限額 …… 200,000円
- 除却費用の1/3 …… 900,000 ÷ 3 ＝ 300,000円
- 延床面積×9,600円の1/3 …… 50 × 9,600 ＝ 480,000円 → ÷3 ＝ 160,000円

最も低いのは<strong>160,000円</strong>です。建物が小さいと、上限の20万円にすら届きません。

<strong>例3：延床100㎡の木造住宅が密集地域にある、解体費用150万円（制度③）</strong>

- 「除却費用150万円」と「100×9,600＝96万円」の<strong>低いほう＝96万円</strong>
- その1/3 …… 320,000円（上限40万円以内）

助成額は<strong>320,000円</strong>です。同じ建物・同じ見積もりでも、<strong>②なら20万円、③なら32万円</strong>と差が出ます。だからこそ、最初に「自分はどの制度か」を見分ける必要があるわけです。

*（計算は名古屋市公式ウェブサイト記載の算定式にもとづく試算です。実際の助成額は市の審査により決まります。制度②は千円未満切り捨て）*

## 名古屋市の解体補助金でつまずく6つの落とし穴

制度の中身がわかったところで、実務で実際につまずく点をまとめます。

1. <strong>交付決定の前に契約・着工すると、一円も出ません</strong>。3制度すべてに共通する最大の落とし穴です。「解体業者から早く決めてほしいと言われて先に契約した」というご相談を毎年いただきますが、この時点で補助は使えなくなります。見積もりを取るのは自由です。<strong>押印の前に市へ</strong>、と覚えてください。
2. <strong>先着受付・予算額に達し次第終了</strong>。老朽危険空家等除却費補助金は先着受付と明記されています。年度の後半に動き出すと、要件を満たしていても枠が残っていないことがあります。
3. <strong>年度末（2月末）の壁</strong>。老朽危険空家等除却費補助金は「交付決定があった日の属する年度の2月末日まで」に工事完了と書類提出等すべての手続きを終える必要があり、戸建木造住宅除却助成も同年度2月末までに完了実績報告書の提出が求められます。<strong>3月31日ではなく2月末</strong>です。解体工事は近隣調整や天候で日程がずれます。年明けからの着工は、かなり綱渡りになります。
4. <strong>所有者全員の同意が要る（老朽危険空家等除却費補助金）</strong>。相続人が複数いて相続登記が済んでいない、共有者と連絡が取れない、という状態では同意が集まらず、申請にたどり着けません。
5. <strong>法人は対象外（老朽危険空家等除却費補助金）</strong>。会社名義で持っている物件では使えません。
6. <strong>市税の滞納があると使えない（老朽危険空家等除却費補助金）</strong>。固定資産税の滞納がある状態では、まず税の整理が先になります。

> **宅建業者の視点**: 4〜6は「建物の問題」ではなく「<strong>持ち主側の事情</strong>」です。建物が完全に条件を満たしていても、名義がまとまらない・滞納があるという理由で補助にたどり着けないケースが実際にあります。この場合、解体を前提にした計画そのものを組み直したほうが早いことが多いです。

## 申請から入金までの流れ｜「補助金は後払い」を前提に資金を考える

3制度に共通する大まかな流れです（詳細は制度・年度により異なります）。

1. <strong>事前相談</strong>：担当課に住所・築年・建物の状況を伝え、どの制度に当たるか、予算枠が残っているかを確認します。
2. <strong>必要書類の準備</strong>：耐震診断（制度②③）、登記事項証明書、所有者の同意書（制度①）、解体業者の見積書などを揃えます。
3. <strong>交付申請</strong>：市へ申請します。<strong>ここで工事契約はまだしません。</strong>
4. <strong>交付決定通知の受取</strong>：この通知が届くまでは、契約も着工もできません。
5. <strong>工事契約 → 着工 → 完了</strong>：年度の2月末という締切から逆算して工程を組みます。
6. <strong>完了実績報告 → 額の確定 → 請求 → 入金</strong>：補助金は<strong>後払い</strong>です。

見落とされやすいのが<strong>6の「後払い」</strong>です。解体費用はいったん<strong>全額を自分で支払う</strong>必要があり、補助金が振り込まれるのはそのあとです。「20万円の助成が出るから」と資金計画を立てても、支払いのタイミングでは満額の現金が必要になります。手元資金が足りない場合は、<strong>解体そのものを前提にしない選択肢</strong>を先に検討したほうが現実的です。

解体費用の工面が難しい場合の考え方は、[相続した実家の解体費用が払えないときの3つの方法](/guide/akiya-kaitai-hiyou-haraenai)で詳しくまとめています。

## 更地にすると固定資産税は上がります｜解体前に必ず確認すること

もう一つ、補助金の情報だけを見ていると抜け落ちる論点があります。<strong>建物を壊して更地にすると、土地の固定資産税が上がる</strong>ということです。

住宅が建っている土地には<strong>住宅用地の特例</strong>が適用され、課税標準額が小規模住宅用地（200平方メートル以下の部分）で6分の1、一般住宅用地で3分の1に軽減されています。この特例は<strong>「住宅が建っていること」が前提</strong>なので、解体して更地にすると特例が外れ、翌年度から土地の税額が上がります。

つまり、<strong>解体費を自己負担で払ったうえに、翌年から税金が上がる</strong>という順番になります。売却がすぐに決まらないと、この状態が続きます。

一方で、<strong>特定空家等や管理不全空家等に指定されて勧告を受けた場合も、住宅用地の特例が外れます</strong>。放置し続けた場合も税負担は上がるということです。詳しくは[空き家の固定資産税が6倍になる条件と比較](/guide/akiya-koteishisanzei-6bai-hikaku)と[特定空家の判定チェックリスト](/guide/tokutei-akiya-hantei-checklist)で整理しています。

> **宅建業者の視点**: 「解体して更地にすれば売りやすくなる」と考える方は多いのですが、更地にした瞬間から<strong>税金の時計が速く回り始めます</strong>。売却の見込みが立っていない段階で先に壊すのは、実はリスクの取り方としては重い選択です。

## 補助金が使えないとき、解体しないという選択肢

ここまで見てきたとおり、名古屋市の解体補助は<strong>建物の条件（築年・構法・耐震診断）</strong>と<strong>場所の条件（密集地域・特定空家等の判断）</strong>と<strong>持ち主の条件（同意・法人・市税）</strong>の3層をすべて通過して、はじめて使えます。どこか1つで外れれば対象外です。

そのときに残る選択肢が、<strong>解体せず、古家付き（現況）のまま買取に出す</strong>という方法です。

| | 補助金を使って解体 → 更地で売る | 古家付き（現況）のまま買取 |
|---|---|---|
| 解体費の負担 | <strong>自己負担が残る</strong>（補助は1/3〜2/3・上限20〜80万円、しかも後払い） | <strong>不要</strong>（解体せずに売る） |
| 残置物の片づけ | 必要になることが多い | そのままで査定できる場合あり |
| 手続き | 耐震診断・交付申請・完了報告など | 査定 → 契約 → 決済 |
| 期間 | 申請から工事・売却まで数ヶ月〜 | 短期間で現金化できるケースあり |
| 固定資産税 | 更地にすると<strong>翌年度から上がる</strong> | 建物がある間は住宅用地の特例が続く |
| 向いている人 | 条件をすべて満たし、時間と資金に余裕がある | 条件を満たさない・早く手放したい・解体費を出したくない |

訳あり物件を専門に扱う買取であれば、<strong>旧耐震・再建築不可・傾きや雨漏りがある家</strong>でも、現況のまま買い取れる場合があります。共有名義や相続登記が済んでいないケースも、状況を伺ったうえでご相談に応じられることがあります。建物の傷みが理由で断られた経験のある方は、[古い空き家・欠陥のある家の買取](/guide/furui-akiya-kekkan-kaitori)もあわせてご覧ください。

## 「補助金で解体」と「現況買取」を手取りで比べる方法

どちらが得かは、立地と建物の状態によって変わります。数字で比べるなら、次の2つを並べます。

<strong>A：補助金を使って解体し、更地で売る場合の手取り</strong>
更地の売却価格 －（解体費用 － 補助金額）－ 仲介手数料等 －（売却までの期間の固定資産税・管理費）

<strong>B：古家付きのまま買い取ってもらう場合の手取り</strong>
買取価格 －（必要な諸費用）

たとえば延床100㎡の旧耐震木造住宅で、解体費用の見積もりが150万円、制度②の助成が20万円だった場合、Aの式では解体だけで<strong>130万円の持ち出し</strong>が確定します。この130万円と、売却までの期間に払い続ける税金・管理費の合計を、更地にすることで上がる売却価格が上回るかどうか。ここが判断の分かれ目です。

Aの見込みは、<strong>解体業者の見積もり</strong>と<strong>更地の想定売却価格</strong>の2つがないと出せません。Bの見込みは、現況のまま査定を受ければ出ます。<strong>先に出せるほうから出して、比較の土台をつくる</strong>のが現実的な進め方です。

## 名古屋市の空き家を手放すときの進め方3ステップ

<img src="/images/nagoya-akiya-kaitai-hojo-2026-soudan.jpg" alt="テーブルで書類を前に不動産の担当者と相談する家族。相続した空き家の売却相談のイメージ" width="1200" height="800" loading="lazy" />

補助金を使って解体するにせよ、古家付きで手放すにせよ、最初にやることは同じです。<strong>「今、いくらで手放せるのか」を知ること</strong>です。
