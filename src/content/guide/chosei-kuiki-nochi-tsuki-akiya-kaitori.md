「実家を相続したけれど、家の横に畑が付いていた」「市街化調整区域だと言われて、仲介に断られた」「畑は誰も耕していないのに、固定資産税だけ毎年かかる」。

<strong>この形の物件でいちばん多い誤解は、家と畑がひとまとめに売れると思ってしまうことです。</strong>実際には、家の敷地（宅地）と畑（農地）は別々の手続きで動きます。そして畑のほうには、宅地にはない<strong>農地法</strong>という法律がかかります。

さらに、その畑が市街化調整区域にあるか市街化区域にあるかで、必要な手続きが<strong>「届出」と「許可」に分かれます</strong>。同じ見た目の畑でも、線引きの内と外で扱いが変わります。

<strong>先に見通しをお伝えします。</strong>家の敷地（宅地）は、通常の売買として進められる可能性があります。畑は農地法の許可の審査があり、通らない場合は、農地のまま耕す人へ渡す道や、解体後に国へ引き取ってもらう道もあります。

この記事では、市街化調整区域・農地付きの空き家について、宅地と何が違うのか、持っているだけで何が発生するのか、誰に何を相談すればよいのかを、条文にあたって整理しました。大阪・兵庫・京都・奈良・滋賀・和歌山の物件についてご相談をお受けしている宅地建物取引業者の立場から書いています。

## 「家と畑」は1つの取引になりません

まず前提として、登記上の1つの不動産は「筆（ふで）」という単位で数えます。実家の敷地が1筆、隣の畑が1筆か2筆、というように分かれていることがほとんどです。

そして<strong>地目（その土地の登記上の種類）が「宅地」か「田・畑」かで、適用される法律が変わります</strong>。

| | 宅地の部分（家の敷地） | 農地の部分（畑・田） |
|---|---|---|
| かかる法律 | 通常の不動産取引のルール | 農地法が上乗せでかかる |
| 権利を移すとき | 当事者の契約で移転できる | そのまま農地として移すなら農業委員会の許可（農地法3条1項） |
| 用途を変えるとき | 原則として自由 | 農地以外にするには許可または届出（同4条1項・5条1項） |
| 取引の相手 | 制限は基本的にない | 農地のまま取得する側に要件がかかる |

先に言葉を補足します。農業委員会は、市町村にある農地の窓口です。都道府県知事等は、農地を農地以外にする許可を出す、都道府県などの長です。農用地区域は、農業を守るために特に指定された区域で、市区町村の農政担当で確認できます。

農地法3条1項は、農地について所有権を移転する場合などには<strong>当事者が農業委員会の許可を受けなければならない</strong>と定めています。買う側が農業をする人でなければ、この許可は下りません。つまり<strong>「畑を畑のまま、誰にでも売る」ことはできません</strong>。

一方、畑を畑以外のもの（宅地や資材置場など）にするために権利を移す場合は、農地法5条1項の手続きになります。ここで市街化調整区域かどうかが効いてきます。

## 市街化調整区域の農地が、宅地といちばん違う点

![市街化調整区域の農地と宅地の違い](/images/chosei-kuiki-nochi-tsuki-akiya-kaitori-h2-1.jpg)

農地法4条1項7号と5条1項6号には、<strong>市街化区域内にある農地について、あらかじめ農業委員会に届け出れば許可を要しない</strong>という例外が置かれています。条文の書き出しは「市街化区域……内にある農地を、政令で定めるところによりあらかじめ農業委員会に届け出て、農地以外のものにする場合」です。

<strong>この例外は、市街化区域内の農地にしか使えません。</strong>市街化調整区域の農地は、原則どおり都道府県知事等の許可が必要です。

| | 市街化区域内の農地 | 市街化調整区域の農地 |
|---|---|---|
| 転用（4条1項） | 農業委員会への事前の届出 | 都道府県知事等の許可 |
| 転用目的の権利移動（5条1項） | 農業委員会への事前の届出 | 都道府県知事等の許可 |
| 根拠 | 4条1項7号・5条1項6号 | 本文（例外規定の適用なし） |

届出は、要件が整っていれば受け付けられる手続きです。許可は、審査を経て可否が判断される手続きです。<strong>「市街化調整区域だから売れない」のではなく、「畑の部分に、可否の審査がある手続きが必要になる」</strong>というのが正確な言い方になります。

なお、許可を受けずにした行為には罰則があり、農地法64条では4条1項・5条1項違反に対して3年以下の拘禁刑または300万円以下の罰金が定められています。手続きを飛ばして進める選択肢はありません。

## 何もしていなくても、農地には義務と調査があります

「耕していないのだから関係ない」と考えられる方が多いのですが、農地は<strong>持っているだけで発生するもの</strong>があります。

### 相続したら、農業委員会への届出が要ります

農地法3条の3は、農地の権利を取得した人に対し、<strong>遅滞なく、その農地のある市町村の農業委員会に届け出なければならない</strong>と定めています。相続で取得した場合も対象です。

届出をしない、または虚偽の届出をした場合は、<strong>10万円以下の過料</strong>の対象です（農地法69条）。登記の名義を変えたかどうかとは別に、農業委員会への届出という手続きが存在します。

### 毎年、利用状況が調査されます

農地法30条1項は、農業委員会が<strong>毎年一回、その区域内にある農地の利用の状況についての調査を行わなければならない</strong>としています。つまり、こちらから何も言わなくても、耕作されていない農地は把握されていきます。

調査の結果、次のような農地は、農地法32条1項により<strong>利用意向調査</strong>の対象になります。「現に耕作の目的に供されておらず、かつ、引き続き耕作の目的に供されないと見込まれる農地」などです。所有者に対して、この農地を今後どうするつもりかを尋ねる調査です。

### 勧告を受けると、税の扱いが変わり得ます

利用意向調査の先には、農地法36条1項による<strong>農地中間管理機構（耕す人へ農地を貸し出す公的な団体）との協議の勧告</strong>があります。

この勧告を受けた農地には、<strong>固定資産税が重くなる方向の価格の特例</strong>があります（地方税法附則17条の3）。具体的な税額は、市区町村の税務課に確認してください。空き家の敷地について、管理不全空家等・特定空家等に指定されると住宅用地の特例から外れる（地方税法349条の3の2）のと、方向としては似た構造になっています。

家のほうにも畑のほうにも、放置に対する仕組みが用意されている、と理解しておいてください。

## 「国に引き取ってもらう」は、家が建っているうちは選べません

![国庫帰属は建物があると使えない](/images/chosei-kuiki-nochi-tsuki-akiya-kaitori-h2-2.jpg)

相続した土地を国庫に帰属させる制度（相続土地国庫帰属制度）を検討される方もいらっしゃいます。ただし、農地付きの空き家では<strong>順番に注意が必要です</strong>。

同法2条3項は、承認申請ができない土地を5つ挙げており、その<strong>1号が「建物の存する土地」</strong>です。残りの4つは次のとおりです。

- 2号：担保権や使用収益を目的とする権利が設定されている土地
- 3号：通路など他人による使用が予定される土地として政令で定めるものが含まれる土地
- 4号：土壌汚染対策法の特定有害物質により汚染されている土地
- 5号：境界が明らかでない土地など、所有権の存否・帰属・範囲に争いがある土地

そして同法5条2項は<strong>「前項の承認は、土地の一筆ごとに行うものとする」</strong>と定めています。家と畑をまとめて1件で処理する制度ではありません。

つまり、実家に空き家が建ったままでは、その筆は申請の入口に立てません。<strong>解体してからでないと使えない制度</strong>だということです。解体費用が先に出ていく点は、判断の前に織り込んでください。

### 負担金は、土地の区分で決まります

結論から言うと、市街化区域・農用地区域・土地改良事業の施行区域のいずれでもない農地は、負担金が一律20万円です。表の計算式は、区分ごとの違いを見るための補足です。なお、家が建っている宅地の筆は、解体するまで申請できません（同法2条3項1号）。

承認された場合、負担金を納めます。金額は施行令5条1項で土地の区分ごとに定められています。

| 土地の区分 | 負担金の算定 |
|---|---|
| 市街化区域内などの宅地（1号） | 地積の区分ごとの計算（50㎡以下なら地積×4,070円＋208,000円 など） |
| 市街化区域内・農用地区域内・土地改良事業の施行区域内の農地（2号） | 地積の区分ごとの計算（250㎡以下なら地積×1,210円＋208,000円 など） |
| 主に森林として利用されている土地（3号） | 地積の区分ごとの計算（750㎡以下なら地積×59円＋210,000円 など） |
| 上記以外の土地（4号） | 一律20万円 |

ここで見落とされやすいのが4号です。<strong>市街化区域内でもなく、農用地区域内でもなく、土地改良事業の施行区域内でもない農地は、2号ではなく4号にあたり、地積にかかわらず20万円</strong>になります。市街化調整区域にある農地のうち、農業振興地域の農用地区域に入っていないものは、この扱いになり得ます。広い畑ほど、地積で計算される場合との差が出ます。

なお、算定した金額に1,000円未満の端数があるときは切り捨てます（施行令5条2項）。また、隣接する2筆以上の土地がいずれも同じ区分に属するときは、<strong>1筆とみなして負担金を算定するよう申し出ることができます</strong>（同6条）。家の跡地と畑が隣り合っている場合、この申出が使えるかどうかで金額が変わります。

## 手放す方向は、大きく4つに分かれます

ここまでを踏まえると、現実的な道筋は次のように整理できます。

| 方向 | 畑の部分に必要なこと | 向いている状況 |
|---|---|---|
| 農地のまま、農業をする人へ渡す | 農地法3条1項の許可（農業委員会） | 近隣に耕してくれる人の当てがある |
| 農地以外にして手放す | 市街化調整区域なら5条1項の許可（都道府県知事等） | 転用の見込みが立つ土地である |
| 不動産として、宅地部分と合わせて相談する | 物件ごとに、どの手続きが使えるかの確認から | 何から手を付けるか自体が決まっていない |
| 解体して国庫帰属を申請する | 建物の解体が前提（2条3項1号）・承認は一筆ごと | 解体費用を出してでも手を離したい |

許可にかかる期間や手数料は、自治体や物件で異なるため、目安の数字はここでは示せません。市区町村の農業委員会に確認できます。当社では、農地部分の扱いも含めて、物件ごとに買取の可否を判断します。解体して国庫帰属を選ぶ場合は、解体費用のほかに負担金がかかります。

「どれが正解か」は、畑が何筆あるか、地目が何か、農用地区域に入っているか、今誰かが耕しているかで変わります。<strong>この4点がわからないうちは、どの方向も選べません。</strong>逆に言えば、この4点を確認するところから相談は始められます。

## 相談する前に、わかる範囲で確認しておくこと

![相談する前に、わかる範囲で確認しておくこと - 空き家のミカタ](/images/chosei-kuiki-nochi-tsuki-akiya-kaitori-h2-3.jpg)

当社では、最初のご相談でわかる範囲の内容をうかがっています。<strong>物件の所在地・物件の種類・入居状況・困っていること</strong>が中心です。<strong>売却を考える時期・手元にある情報・現地確認について伝えたいこと・相談して確認したいこと</strong>もあれば教えてください。記入しにくい欄は「不明」「未定」で構いません。氏名・連絡先・口座番号・身分証明書を先に用意していただく必要もありません。

農地が付いている場合は、これに次の項目が加わると話が具体的になります。

| 確認すること | 書いておくと早い内容 |
|---|---|
| 家と畑の筆数 | 宅地◯筆・農地◯筆／不明 |
| 登記の地目 | 宅地／田／畑／山林／不明（課税明細書に記載があります） |
| 市街化区域か調整区域か | 市街化区域／市街化調整区域／不明（市区町村の都市計画担当に確認できます） |
| 農用地区域に入っているか | 入っている／入っていない／不明（負担金の区分に関わります） |
| 今の耕作の状況 | 自分で耕している／誰かに任せている／誰も耕していない／不明 |
| 農業委員会への届出 | 相続時に届け出た／届け出ていない／不明 |
| 建物の状態 | 住める／傷んでいる／解体を考えている／未定 |

<strong>すべてが「不明」でも相談は始められます。</strong>地目も区域も、課税明細書や市区町村の窓口で確認できる事項です。確認できてから連絡しよう、と待つほど、選べる方向が減っていきます。

大阪の市街化調整区域の物件も、滋賀や和歌山の農地付きの物件も、確認する順番は同じです。物件の所在地が大阪・兵庫・京都・奈良・滋賀・和歌山であれば、所有者の方がどこにお住まいでもご相談をお受けしています。

## よくある質問

<strong>Q. 市街化調整区域にある農地付きの空き家は、買い取ってもらえますか？</strong>
所在地と物件の状況を確認したうえで判断します。ここで大事なのは、家（宅地）と畑（農地）が1つの取引にまとまらない点です。宅地部分は通常の売買として進められますが、農地部分は農地法の手続きが別途必要です。農地のまま権利を移すには農業委員会の許可（農地法3条1項）、農地以外にするために権利を移すには都道府県知事等の許可（同5条1項）が要ります。「買えるかどうか」ではなく「農地部分にどの手続きが使えるか」を先に確認することになります。

<strong>Q. 宅地と農地で、何がそんなに違うのですか？</strong>
農地には農地法がかかります。特に差が出るのが市街化区域かどうかです。市街化区域内の農地であれば、農地以外にする転用は農業委員会への事前の届出で足ります（農地法4条1項7号・5条1項6号）。市街化調整区域の農地にはこの例外の適用がなく、原則どおり都道府県知事等の許可が必要です。同じ「畑」でも、線引きの内か外かで届出と許可に分かれます。

<strong>Q. 相続した農地を、何もせずに持っているだけでも手続きは要りますか？</strong>
要ります。相続などで農地の権利を取得した人は、遅滞なくその農地のある市町村の農業委員会へ届け出る義務があります（農地法3条の3）。届出をしない、または虚偽の届出をした場合は10万円以下の過料と定められています（同69条）。耕していないから関係ない、という扱いにはなりません。

<strong>Q. 使っていない畑を放っておくと、どうなりますか？</strong>
農業委員会は毎年1回、区域内の農地の利用状況を調査します（農地法30条1項）。耕作されておらず今後も耕作される見込みがない農地には利用意向調査が行われ（同32条1項）、その先に農地中間管理機構との協議の勧告（同36条1項）があります。この36条1項の勧告を受けた農地は、地方税法附則17条の3で固定資産税の価格の特例が定められており、税の負担が変わる可能性があります。

<strong>Q. 空き家ごと国に引き取ってもらうことはできますか？</strong>
建物が建っている状態ではできません。相続土地国庫帰属制度は、建物の存する土地について承認申請自体ができないと定めています（同法2条3項1号）。承認は一筆ごとに行われるため（同5条2項）、家を解体したうえで宅地の筆と農地の筆をそれぞれ申請する形になります。負担金は土地の区分ごとに決まっています。市街化区域内でも農用地区域内でも土地改良事業の施行区域内でもない農地は、施行令5条1項4号の「前三号に掲げる土地以外の土地」として一律20万円です。

<strong>Q. まだ何も調べていませんが、この状態で相談していいですか？</strong>
そのままお聞かせください。最初に必要なのは、物件の市区町村・物件の種類・入居状況・困っていることを、わかる範囲で伝えることです。農地が付いている場合は、これに加えて「畑が何筆あるか」「登記の地目は何か」「今誰かが耕しているか」がわかれば話が早く進みますが、いずれも不明のままで構いません。

## まとめ

- 農地付きの空き家は、<strong>家（宅地）と畑（農地）で手続きが分かれます</strong>。1つの取引にはまとまりません。
- 農地を農地のまま移すには農業委員会の許可（農地法3条1項）、農地以外にするために移すには許可が必要です（同5条1項）。
- 市街化区域内の農地には<strong>届出で足りる例外</strong>があります（同4条1項7号・5条1項6号）。<strong>市街化調整区域の農地にはこの例外がありません</strong>。
- 相続したら<strong>農業委員会への届出義務</strong>があり（同3条の3）、違反は10万円以下の過料です（同69条）。放置した農地は毎年の利用状況調査（同30条1項）から利用意向調査（同32条1項）、勧告（同36条1項）へ進み、地方税法附則17条の3の特例に関わります。
- <strong>建物が建っているうちは国庫帰属を申請できません</strong>（同法2条3項1号）。承認は一筆ごと（同5条2項）、負担金は区分ごとで、市街化区域外・農用地区域外の農地は一律20万円です（施行令5条1項4号）。
- 相談の入口では、<strong>筆数・地目・区域・耕作の状況</strong>がわかると早く進みます。すべて「不明」のままでも始められます。
