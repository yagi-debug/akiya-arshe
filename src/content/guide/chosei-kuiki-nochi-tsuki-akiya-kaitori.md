「実家を相続したけれど、家の横に畑が付いていた」「市街化調整区域だと言われて、仲介に断られた」「畑は誰も耕していないのに、固定資産税だけ毎年かかる」。

<strong>この形の物件でいちばん多い誤解は、家と畑がひとまとめに売れると思ってしまうことです。</strong>実際には、家の敷地（宅地）と畑（農地）は別々の手続きで動きます。そして畑のほうには、宅地にはない<strong>農地法</strong>という法律がかかります。

さらに、その畑が市街化調整区域にあるか市街化区域にあるかで、必要な手続きが<strong>「届出」と「許可」に分かれます</strong>。同じ見た目の畑でも、線引きの内と外で扱いが変わります。

<strong>先に結論です。手放す方向は4つあります。</strong>農地のまま貸すか譲る、許可を得て農地以外にする、宅地と合わせて不動産として相談する、家を解体して国に引き取ってもらう、の4つです。家の敷地（宅地）は売れる可能性が高い一方、調整区域では買い手が限られることがあります。当社が買えるかは、物件を確認してからお答えします。

どの方向になるかは、畑が何筆（ふで。登記上の土地を数える単位）あるか、登記の地目（土地の種類）が何か、農用地区域に入っているか、今誰かが耕しているかで決まります。国に引き取ってもらう道は、家を解体しても審査に通らないことがあります。

この記事では、市街化調整区域・農地付きの空き家について、宅地と何が違うのか、持っているだけで何が発生するのか、誰に相談すればよいのかを整理しました。条文番号は末尾の出典欄にまとめています。大阪・兵庫・京都・奈良・滋賀・和歌山の物件についてご相談をお受けしている宅地建物取引業者の立場から書いています。

## 「家と畑」は1つの取引になりません

まず前提として、登記上の土地は「筆（ふで）」という単位で数えます。実家の敷地が1筆、隣の畑が1筆か2筆、というように分かれていることがほとんどです。

そして<strong>地目（その土地の登記上の種類）が「宅地」か「田・畑」かで、適用される法律が変わります</strong>。

| | 宅地の部分（家の敷地） | 農地の部分（畑・田） |
|---|---|---|
| かかる法律 | 通常の不動産取引のルール | 農地法が上乗せでかかる |
| 権利を移すとき | 当事者の契約で移転できる | そのまま農地として移すなら農業委員会の許可 |
| 用途を変えるとき | 原則として自由 | 農地以外にするには許可または届出 |
| 取引の相手 | 制限は基本的にない | 農地のまま取得する側に要件がかかる |

先に言葉を補足します。地目は、登記上の土地の種類です。農業委員会は、市町村にある農地の窓口です。転用は、畑を宅地や駐車場など農地以外に変えることです。都道府県知事等は、転用の許可を出す、都道府県などの長です。

農用地区域は、農業を守るために特に指定された区域です。市区町村の農政担当で確認できます。

許可は目的で分かれます。窓口は、どちらもまず市町村の農業委員会です。

- 畑のまま人に譲る：農業委員会の許可
- 畑をやめて宅地などにする：都道府県知事等の許可（申請は農業委員会を通します）

畑のまま譲る場合、買う側が農業をする人でなければ、許可は下りません。つまり<strong>「畑を畑のまま、誰にでも売る」ことはできません</strong>。

一方、畑を畑以外のもの（宅地や資材置場など）にするために権利を移す場合は、別の手続きになります。ここで市街化調整区域かどうかが効いてきます。

## 市街化調整区域の農地が、宅地といちばん違う点

![市街化調整区域の農地と宅地の違い](/images/chosei-kuiki-nochi-tsuki-akiya-kaitori-h2-1.jpg)

農地法には、<strong>市街化区域内にある農地なら、あらかじめ農業委員会に届け出れば許可は要らない</strong>という例外があります。

<strong>この例外は、市街化区域内の農地にしか使えません。</strong>市街化調整区域の農地は、原則どおり都道府県知事等の許可が必要です。

| | 市街化区域内の農地 | 市街化調整区域の農地 |
|---|---|---|
| 自分の畑を転用する | 農業委員会への事前の届出 | 都道府県知事等の許可 |
| 転用のために権利を移す | 農業委員会への事前の届出 | 都道府県知事等の許可 |

届出は、要件が整っていれば受け付けられる手続きです。許可は、審査を経て可否が判断される手続きです。<strong>「市街化調整区域だから売れない」のではなく、「畑の部分に、可否の審査がある手続きが必要になる」</strong>というのが正確な言い方になります。

なお、許可を受けずに転用すると罰則があり、3年以下の拘禁刑または300万円以下の罰金が定められています。手続きを飛ばして進める選択肢はありません。

市街化調整区域では、家を建て替える、新たに建てるのに、別の許可が要る場合があります。そのため買い手が限られ、仲介に断られやすくなります。その場合でも、買取のご相談はできます。

## 何もしていなくても、農地には義務と調査があります

「耕していないのだから関係ない」と考えられる方が多いのですが、農地は<strong>持っているだけで発生するもの</strong>があります。

### 相続したら、農業委員会への届出が要ります

農地の権利を取得した人は、<strong>遅滞なく、その農地のある市町村の農業委員会に届け出なければなりません</strong>。相続で取得した場合も対象です。

届出をしない、または虚偽の届出をした場合は、<strong>10万円以下の過料</strong>の対象です。登記の名義を変えたかどうかとは別に、農業委員会への届出という手続きが要ります。

### 毎年、利用状況が調査されます

農業委員会は、<strong>毎年一回、区域内にある農地の利用の状況を調査します</strong>。こちらから何も言わなくても、耕作されていない農地は把握されていきます。

調査の結果、今は耕されておらず今後も耕される見込みがない農地は、<strong>利用意向調査</strong>の対象になります。所有者に、この農地を今後どうするつもりかを尋ねる調査です。

### 勧告を受けると、税額が上がる場合があります

利用意向調査の先には、<strong>農地中間管理機構（耕す人へ農地を貸し出す公的な団体）との協議の勧告</strong>があります。

勧告を受けると、固定資産税の農地向けの軽減が外れ、一般の土地に近い評価になることがあります。増える額は土地ごとに違います。まず今年の課税明細書で現在の税額を確認し、市区町村の税務課に見込みを聞いてください。

## 「国に引き取ってもらう」は、家が建っているうちは選べません

![国庫帰属は建物があると使えない](/images/chosei-kuiki-nochi-tsuki-akiya-kaitori-h2-2.jpg)

相続した土地を国庫に帰属させる制度（相続土地国庫帰属制度）を検討される方もいらっしゃいます。ただし、農地付きの空き家では<strong>順番に注意が必要です</strong>。

この制度では、申請できない土地が決まっており、その筆頭が<strong>「建物が建っている土地」</strong>です。担保権が付いた土地、境界が不明な土地なども申請できません。

申請できても、<strong>引き取ってもらえるとは限りません</strong>。国の審査があり、通常の管理や処分に過分の費用や労力がかかる土地などは、承認されません。審査は一筆ごとに行われ、家と畑をまとめて1件で処理する制度でもありません。

つまり、空き家が建ったままでは、その筆は申請できません。<strong>解体してからでないと使えない制度</strong>で、解体しても通らない場合があります。解体費用が先に出ていく点は、判断の前に織り込んでください。

### 負担金は、畑の場所で2通りです

承認されると、負担金を納めます。これは解体費とは別のお金です。承認されたあとの話で、審査に通らなければ納めません。

- あなたの畑が農用地区域・市街化区域・土地改良事業の区域の外なら、面積に関係なく一律20万円です。
- 農用地区域などの内側にあるなら、面積に応じた計算になり、20万円より高くなることがあります。

市街化調整区域の畑でも、農用地区域に入っていれば後者です。入っているかどうかは、市区町村の農政担当で確認できます。

隣り合う2筆以上の土地が同じ区分なら、<strong>1筆とみなして負担金を計算するよう申し出ることができます</strong>。家の跡地と畑が隣り合っていれば、この申出が使えるかで金額が変わります。

## 手放す方向は、大きく4つに分かれます

ここまでを踏まえると、現実的な道筋は次のように整理できます。

| 方向 | 畑の部分に必要なこと | 向いている状況 |
|---|---|---|
| 農地のまま、農業をする人へ渡す | 農業委員会の許可 | 近隣に耕してくれる人の当てがある |
| 農地以外にして手放す | 市街化調整区域なら都道府県知事等の許可 | 転用の見込みが立つ土地である |
| 不動産として、宅地部分と合わせて相談する | 物件ごとに、どの手続きが使えるかの確認から | 何から手を付けるか自体が決まっていない |
| 解体して国へ引き取りを申し出る | 建物の解体が前提。審査に通らないこともある | 解体費用を出してでも手を離したい |

近隣に耕してくれる人の当てがない場合は、農業委員会や農地中間管理機構に、貸したい・譲りたい農地として相談できます。

許可の期間や手数料は自治体や物件で異なるため、数字はここでは示せません。市区町村の農業委員会で確認できます。

当社の対応は、物件を確認してから、次の3つのどれかに分けてお伝えします。

- 畑を含めて買い取れる場合
- 宅地だけ買い取る場合
- 農地は別に手続きが必要な場合

買取価格は物件しだいで、ここでは示せません。費用がかかる項目と、負担する人は次のとおりです。

- 農地の許可申請の費用：条件の確認時に、負担する人を先にお伝えします
- 建物の解体費（国へ引き取りを申し出る場合）：所有者の方のご負担です
- 国庫帰属の負担金（承認後）：所有者の方のご負担です。20万円で済む場合は前述のとおりです

「どれが正解か」は、畑が何筆あるか、地目が何か、農用地区域に入っているか、今誰かが耕しているかで変わります。<strong>この4点がわからないうちは、どの方向も選べません。</strong>逆に言えば、この4点を確認するところから相談は始められます。

## 相談する前に、わかる範囲で確認しておくこと

![相談する前に、わかる範囲で確認しておくこと - 空き家のミカタ](/images/chosei-kuiki-nochi-tsuki-akiya-kaitori-h2-3.jpg)

当社では、最初のご相談でわかる範囲の内容をうかがっています。<strong>物件の所在地・物件の種類・入居状況・困っていること</strong>が中心です。<strong>売却を考える時期・手元にある情報・現地確認について伝えたいこと・相談して確認したいこと</strong>もあれば教えてください。記入しにくい欄は「不明」「未定」で構いません。氏名・連絡先・口座番号・身分証明書を先に用意していただく必要もありません。

農地が付いている場合は、これに次の項目が加わると話が具体的になります。

| 確認すること | 書いておくと早い内容 |
|---|---|
| 家と畑の筆数 | 宅地◯筆・農地◯筆／不明 |
| 登記の地目 | 宅地／田／畑／山林／不明（課税明細書に記載があります） |
| 市街化区域か調整区域か | 市街化区域／市街化調整区域／不明（市区町村の都市計画担当に確認できます） |
| 農用地区域に入っているか | 入っている／入っていない／不明（負担金の区分に関わります） |
| 今の耕作の状況 | 自分で耕している／誰かに任せている／誰も耕していない／不明 |
| 農業委員会への届出 | 相続時に届け出た／届け出ていない／不明 |
| 建物の状態 | 住める／傷んでいる／解体を考えている／未定 |

<strong>すべてが「不明」でも相談は始められます。</strong>地目も区域も、課税明細書や市区町村の窓口で確認できる事項です。確認できてから連絡しよう、と待つほど、選べる方向が減っていきます。

大阪の市街化調整区域の物件も、滋賀や和歌山の農地付きの物件も、確認する順番は同じです。物件の所在地が大阪・兵庫・京都・奈良・滋賀・和歌山であれば、所有者の方がどこにお住まいでもご相談をお受けしています。

## よくある質問

<strong>Q. 市街化調整区域にある農地付きの空き家は、買い取ってもらえますか？</strong>
宅地は売れる可能性が高い一方、調整区域では買い手が限られます。畑は許可しだいで、当社が買えるかは物件を確認してからお答えします。家と畑は1つの取引にまとまらず、農地部分には別の手続きが要ります。農地のまま移すなら農業委員会の許可、農地以外にするなら都道府県知事等の許可です。畑を含めて買う場合、宅地だけ買う場合、農地は別手続きの場合に分けてご案内します。

<strong>Q. 宅地と農地で、何がそんなに違うのですか？</strong>
農地には農地法がかかります。特に差が出るのが市街化区域かどうかです。市街化区域内の農地なら、農地以外にする転用は農業委員会への事前の届出で足ります。市街化調整区域の農地にはこの例外がなく、都道府県知事等の許可が必要です。同じ「畑」でも、線引きの内か外かで届出と許可に分かれます。

<strong>Q. 相続した農地を、何もせずに持っているだけでも手続きは要りますか？</strong>
要ります。相続などで農地の権利を取得した人は、遅滞なくその農地のある市町村の農業委員会へ届け出る義務があります。届出をしない、または虚偽の届出をした場合は10万円以下の過料です。耕していないから関係ない、という扱いにはなりません。

<strong>Q. 使っていない畑を放っておくと、どうなりますか？</strong>
農業委員会は毎年1回、区域内の農地の利用状況を調査します。耕されておらず今後も耕される見込みがない農地には、利用意向調査が行われます。その先に、農地中間管理機構との協議の勧告があります。勧告を受けると、農地向けの軽減が外れて税額が上がることがあります。今年の課税明細書で現在の税額を確認し、税務課に見込みを聞いてください。

<strong>Q. 空き家ごと国に引き取ってもらうことはできますか？</strong>
建物が建っている状態ではできません。相続土地国庫帰属制度は、建物が建つ土地の申請を認めていません。家を解体したうえで、宅地の筆と農地の筆をそれぞれ申請する形になります。解体しても、審査に通らない場合があります。農用地区域・市街化区域・土地改良事業の区域の外の農地なら、負担金は一律20万円です。解体費とは別で、承認後に納めます。

<strong>Q. まだ何も調べていませんが、この状態で相談していいですか？</strong>
そのままお聞かせください。最初に必要なのは、物件の市区町村・物件の種類・入居状況・困っていることを、わかる範囲で伝えることです。農地が付いている場合は、これに加えて「畑が何筆あるか」「登記の地目は何か」「今誰かが耕しているか」がわかれば話が早く進みますが、いずれも不明のままで構いません。

## まとめ

- 農地付きの空き家は、<strong>家（宅地）と畑（農地）で手続きが分かれます</strong>。1つの取引にはまとまりません。
- 農地を農地のまま移すには農業委員会の許可、農地以外にするために移すには許可が必要です。
- 市街化区域内の農地には<strong>届出で足りる例外</strong>があります。<strong>市街化調整区域の農地にはこの例外がありません</strong>。
- 相続したら<strong>農業委員会への届出義務</strong>があり、違反は10万円以下の過料です。放置した農地は毎年の調査、利用意向調査、勧告へ進み、税額が上がる場合があります。
- <strong>建物が建っているうちは国へ引き取りを申し出られません</strong>。解体しても審査に通らない場合があります。農用地区域などの外の農地は、負担金が一律20万円です。
- 相談の入口では、<strong>筆数・地目・区域・耕作の状況</strong>がわかると早く進みます。すべて「不明」のままでも始められます。
