## 神戸市の空き家解体補助金は「面積で決まる定額」｜2026年度の上限額早見表

まず金額です。神戸市老朽空家等解体補助制度の補助額は、<strong>解体する補助対象建物の登記床面積または課税床面積</strong>で決まります。

| 登記床面積または課税床面積の合計 | 補助金額 |
|---|---|
| 30㎡未満 | <strong>20万円</strong> |
| 30㎡以上 | <strong>30万円</strong> |
| 40㎡以上 | <strong>40万円</strong> |
| 50㎡以上 | <strong>45万円</strong> |
| 60㎡以上 | <strong>50万円</strong> |
| 70㎡以上 | <strong>55万円</strong> |
| 80㎡以上 | <strong>60万円</strong> |

（出典: 神戸市公式ウェブサイト／2026年9月1日確認）

ここで大事なのは、<strong>解体費がいくらかかったかは金額に影響しない</strong>ことです。延べ85㎡の木造住宅なら、解体費が150万円でも250万円でも補助は60万円です。他都市の「工事費の3分の1」型とは、この点が根本的に違います。

ただし、逆方向に1つだけ制限があります。市のQ&Aの表の下には、こう注記されています。

> ※補助対象事業費が上限額

つまり<strong>解体工事費そのものが上限になる</strong>ということです。たとえば延べ25㎡の物置を18万円で解体する場合、表の区分は「30㎡未満＝20万円」ですが、工事費18万円を超える補助は出ません。小さい附属建物だけを壊すケースでは、ここで表の額に届かないことがあります。

<strong>ポイント整理</strong>

- 補助額は<strong>面積で決まる定額</strong>。工事費の割合ではない
- <strong>80㎡以上はすべて60万円</strong>。120㎡でも200㎡でも一般の建物なら60万円で頭打ち（共同住宅・寄宿舎は次章の別表）
- 工事費が表の額より低いときは<strong>工事費が上限</strong>

## 共同住宅・寄宿舎なら上限100万円｜相続したアパート・文化住宅が該当する条件

相続したアパートや、神戸市内に多く残る文化住宅・長屋形式の建物を持っている方は、こちらの表を先に見てください。

<strong>用途が共同住宅・寄宿舎に該当する建物で、登記床面積または課税床面積が100㎡以上、かつ3戸以上の住戸がある場合</strong>は、別表が適用されます。

| 登記床面積または課税床面積の合計 | 補助金額 |
|---|---|
| 100㎡以上 | <strong>70万円</strong> |
| 110㎡以上 | <strong>75万円</strong> |
| 120㎡以上 | <strong>80万円</strong> |
| 130㎡以上 | <strong>85万円</strong> |
| 140㎡以上 | <strong>90万円</strong> |
| 150㎡以上 | <strong>95万円</strong> |
| 160㎡以上 | <strong>100万円</strong> |

（出典: 神戸市公式ウェブサイト／2026年9月1日確認）

条件は2つあり、両方を満たす必要があります。

1. <strong>用途</strong>: 建物の「登記事項証明書」「固定資産課税台帳登録事項証明書」「固定資産課税台帳の写し」のいずれかに<strong>「共同住宅」もしくは「寄宿舎」</strong>の記載があること
2. <strong>戸数</strong>: 「共同住宅」もしくは「寄宿舎」の用途に供する<strong>住戸が3戸以上</strong>あること

ここは実務でつまずきやすい場所です。<strong>実際に3世帯が住んでいた建物でも、登記や課税台帳の種類が「居宅」になっていれば別表は使えません</strong>。判定は現況ではなく書面の記載です。相続したアパートの登記事項証明書を取ったら、まず種類の欄を確認してください。

もう1つ、境界の話をします。一般の表と別表は、<strong>100㎡のところで10万円の段差</strong>があります。

- 課税床面積99㎡の共同住宅 → 一般表の「80㎡以上」＝<strong>60万円</strong>
- 課税床面積100㎡の共同住宅（3戸以上） → 別表の「100㎡以上」＝<strong>70万円</strong>

1㎡で10万円変わるわけですが、<strong>面積は書面の記載値なので操作できません</strong>。だからこそ、申請前に登記事項証明書と課税明細書の両方を取って、<strong>どちらの数字で申請すると区分が上がるか</strong>を窓口に確認する価値があります。市のQ&Aは「登記事項証明書」「固定資産課税台帳登録事項証明書」「固定資産課税台帳の写し」のいずれかに記載の面積で算定すると書いており、どれか1つに限定していません。

相続したアパートについては、そもそも解体するかどうかから考える必要があります。入居者がいれば解体はできず、賃貸中のまま売ったほうが手残りが大きいことも多いためです。詳しくは[相続したアパートの買取｜空室・老朽化・入居者ありでも売れる方法](/guide/inherited-apartment-buyout)をご覧ください。

## 自分の空き家はいくら出るのか｜面積の数え方でつまずく3つの落とし穴

定額制は一見わかりやすいのですが、「自分の建物が何㎡として数えられるか」でつまずきます。神戸市のQ&Aが明記している数え方のルールは3つです。

<strong>ルール1: 複数棟ある場合は各棟の合計</strong>

母屋70㎡＋登記済みの倉庫15㎡なら、合計85㎡＝<strong>60万円</strong>です。母屋だけで見て「70㎡以上＝55万円」と思っていると5万円損をします。

<strong>ルール2: 書面に記載のない未登記の増築・別棟は算入しない</strong>

Q&Aはこう書いています。

> これら資料に記載のない別棟の建物や増築等の床面積および、1987年（昭和62年）1月1日以降に建てられた別棟の建物は算入しません。

つまり母屋1階が登記済み・2階の増築が未登記なら、<strong>2階部分は面積に入りません</strong>。

<strong>ルール3: 1987年1月1日以降に建てられた別棟は算入しない</strong>

補助対象は1986年12月31日以前の建物なので、あとから建てた別棟は面積に入らないという整理です。

そして、ここが神戸市の制度で一番誤解されるところです。<strong>面積に算入されない建物でも、解体除却の義務からは外れません。</strong>市のQ&Aは、敷地内の附属建物・門・塀・車庫・生垣なども原則すべて解体除却することが補助の要件だと明記しています。

言い換えると、<strong>未登記の倉庫は「壊さなければ補助が出ないのに、補助額の計算には入らない」</strong>という扱いです。解体費だけが増えて、補助額は増えません。見積もりを取る段階で、この非対称を頭に入れておいてください。

<strong>計算例（数え方の違いで補助額がどう変わるか）</strong>

| ケース | 面積の数え方 | 補助額 |
|---|---|---|
| 母屋（登記）72㎡のみ | 72㎡ | 55万円 |
| 母屋（登記）72㎡＋倉庫（登記）12㎡ | 84㎡ | <strong>60万円</strong> |
| 母屋（登記）72㎡＋倉庫（未登記）12㎡ | 72㎡（倉庫は算入せず・ただし解体は必要） | 55万円 |
| 母屋（登記）72㎡＋2000年築の離れ（登記）20㎡ | 72㎡（1987年以降の別棟は算入せず） | 55万円 |

（金額は上記の補助金額表にもとづく計算例です。面積算定の最終判断は窓口で行われます）

なお、敷地内に建物が2棟あってどちらか1棟だけを解体したい場合、Q&Aは「原則、全ての建物の解体が必要」としつつ、<strong>各建物の用途が独立している場合（1棟は自己居住、別棟は賃貸用住宅だった場合など）は建物ごとに申請できる場合がある</strong>と書いています。該当しそうなら、必要書類が別にあるので窓口で確認してください。

## 対象になる空き家の条件｜1986年12月31日以前＋腐朽・破損＋申請日前に空き家

| 項目 | 内容 |

| 状態 | <strong>腐朽・破損のある空き家</strong> |
| 用途 | <strong>住宅以外の用途も対象</strong>（店舗・倉庫等も可） |
| 空き家である期間 | <strong>補助金の申請をする日より前に空き家であればよい</strong>（○年以上という下限なし） |
| 申請者 | <strong>空き家の所有者等（個人も法人も対象）</strong> |
| 跡地の使い方 | <strong>建て替えか売却かなどの要件はない</strong> |

（出典: 神戸市公式ウェブサイト・2026年度申請手引き・Q&A／2026年9月1日確認）

この表のうち、他都市と比べて明確に有利な点が3つあります。

<strong>1つ目は、空き家期間の下限がないことです。</strong>「原則1年以上使用されていないこと」を条件にする自治体は多いのですが、神戸市のQ&Aは「補助金の申請をする日より前に空き家である必要があります」だけです。親が亡くなって間もない実家でも、申請日時点で空き家になっていれば要件を満たします。

<strong>2つ目は、法人が申請できることです。</strong>政令市の解体補助では個人限定の自治体もあります。神戸市は「個人も法人も対象」と明記しています。

<strong>3つ目は、跡地の使い方に条件がないことです。</strong>Q&Aは「解体後の跡地の活用方法（建て替えするか売却するかなど）についての要件はありません」と書いています。跡地を地域に無償で貸すことを条件にする自治体もあるなかで、<strong>解体後にすぐ売却してもよい</strong>のは実務上とても大きい違いです。

一方、補助対象外になるものも手引きに列挙されています。

- 宗教活動、政治活動に資するもの
- 老朽空き家等が歴史的価値を有するなど、補助事業の目的に合わないもの
- <strong>国又は地方公共団体等による他の補助金の交付および公共事業の補償を受けるもの</strong>

3つ目は要注意です。道路事業などで補償が出るケースは、この補助と重ねられません。

## 「腐朽・破損」はどこを見られるのか｜5部位の判定と写真の撮り方

「腐朽・破損のある空き家」という条件を見て、「うちはまだそこまで傷んでいないから対象外かもしれない」と考える方が多いのですが、神戸市の判定基準は手引きに具体的に書かれています。<strong>①〜⑤の各部位のいずれかに、腐朽・破損の状態が目視で確認できること</strong>です。

| 部位 | 手引きが挙げる状態の例 |
|---|---|
| ①屋根 | 屋根ぶき材料の剥落・ずれ、屋根の変形 など |
| ②軒、庇 | 軒・庇の落下・破損、軒天井材・垂木等の腐朽・剥落・落下の恐れのあるひび割れ など |
| ③外壁 | 外壁の剥落・落下の恐れのあるひび割れ、外壁タイル・仕上げ材の剥落・落下の恐れのあるひび割れ・浮き・孕み、金属系仕上げ材の腐食 など |
| ④バルコニー、屋外階段等 | バルコニーの剥落・腐朽・破損、外廊下の天井剥落・床ひび割れ、支柱・屋外階段の腐朽・腐食・破損 など |
| ⑤基礎、土台、柱、梁 | 基礎の不同沈下・破損・ひび割れ、土台・柱・梁の腐朽・破損・変形、柱の傾斜 など |

（出典: 神戸市 2026年度老朽空家等解体補助制度 申請手引き／2026年9月1日確認）

<strong>「いずれか」1か所で足ります。</strong>屋根瓦が数枚ずれている、軒天井にひび割れがある、金属板の外壁に錆が出ている——このレベルで要件に入ります。1980年代以前の木造住宅で、数年放置されている建物なら、①〜③のどこかは該当しているのが普通です。

ただし、除外がはっきり書かれています。

> ※コンクリート土間や外構（コンクリートブロック塀・擁壁等）のひび割れ、破損は要件対象外です。

<strong>「ブロック塀が崩れかけている」は腐朽・破損の理由になりません。</strong>建物本体（外部）で判定されます。神戸市は坂の多い街で擁壁のある敷地が多いため、ここを勘違いしやすい点です。

![老朽化した木造住宅の解体工事｜足場が組まれ解体工事のお知らせが掲示された空き家](/images/kobe-akiya-kaitai-hojo-2026-kaitai.jpg)

写真の撮り方も手引きに指定があります。提出するのは次の4種類です。

- <strong>建物全景写真（複数枚）</strong>: 敷地全体や前面道路が写るように。1枚に収まらない場合や複数の道に接している場合は方向を変えて複数枚
- <strong>腐朽・破損状態がわかる写真</strong>: 建物本体の外部で、主な破損1〜2箇所程度
- <strong>共同住宅の場合</strong>: 玄関扉や集合ポストの写真（または建物平面図など戸数のわかるもの）
- <strong>除却できない工作物がある場合</strong>: その工作物がわかる写真

現況写真は<strong>A4サイズの用紙にカラー印刷</strong>して提出します（印刷できない場合は貼り付けでも可）。撮りにくい屋根はカメラのズーム機能を使うよう手引きに書かれています。遠方に住んでいて現地に行けない方は、この写真の要件が最初のハードルになります。

## 門・塀・車庫・立木まで全部壊すのが原則｜見積書が膨らむ本当の理由

神戸市の制度でもっとも見積額に影響するのが、この条件です。

> 原則として、空き家と敷地内の附属する建物、道に面する門・塀類、車庫・カーポート、立木竹等を全て解体除却することが条件です。

（出典: 神戸市公式ウェブサイト／2026年9月1日確認）

Q&Aでも、倉庫・蔵・門・車庫・生垣なども原則として解体除却する必要があると明記されています。<strong>建物だけ壊して門と塀を残す、という進め方はできません。</strong>

これは金額に直結します。定額制なので<strong>補助額は増えないのに、壊す対象は増える</strong>という構図です。庭木の伐根、ブロック塀の撤去、カーポートの解体は、それぞれ数万円から数十万円かかります。

例外もあります。手引きは、独立した堀込車庫が土留め擁壁を兼ねているなどの理由で残す場合について、<strong>当該車庫が対象建物と直接つながっていないことを確認できる内部全体の写真</strong>を追加で求めています。つまり「構造上どうしても残さなければならないもの」は、写真で説明すれば残置できる余地があります。六甲山麓の斜面地に建つ神戸市の住宅では、この判断が実際によく出てきます。

<strong>見積もりを取るときの実務</strong>

- 業者に「補助金を使う前提で、門・塀・車庫・立木竹の撤去まで含めた見積書」を依頼する
- 費目を<strong>建物本体／附属建物／門塀・車庫／立木竹／残置物処分</strong>に分けて出してもらう
- 残置物（家財道具）の処分費は、補助額とは関係なく実費でかかる。分けて把握しておく

解体費そのものの水準感は、地域と構造・接道で大きく変わります。近畿圏の解体費の内訳と相場の考え方は[大阪の解体費用相場2026年版](/guide/osaka-kaitai-hiyou-soba-2026)で整理しています。

## 申請期間と締切｜2027年1月12日より先に「予算切れ」と「3月11日」が来る

日程を、公式に書かれているまま並べます。

| 手続き | 期限 |
|---|---|
| 申請受付開始 | 2026年3月2日（月曜日） |
| 申請受付終了 | <strong>2027年1月12日（火曜日）</strong>（※<strong>予算がなくなり次第終了</strong>） |
| 審査 | 交付申請から交付決定まで<strong>約1ヵ月</strong>（すまいるネット記載） |
| 契約・工事着手 | <strong>交付決定通知を受けたあと</strong> |
| 実績報告 | 工事完了・支払をしてから<strong>30日以内</strong> |
| 実績報告の最終締切 | <strong>2027年3月11日（木曜日）</strong>（間に合わない場合は補助を受けられません） |

（出典: 神戸市 2026年度申請手引き・すまいるネット／2026年9月1日確認）

この表を読むときのコツは、<strong>受付終了日（1月12日）を締切だと思わないこと</strong>です。実際に効いてくる締切は2つ、先に来ます。

<strong>1つ目は予算切れです。</strong>手引きは「予算がなくなり次第終了します」と書いています。神戸市は予算総額や執行率を公開していないため、外から残枠を読むことはできません。この記事を書いている2026年9月1日から受付終了日までは133日ありますが、その全期間が使える保証はありません。

<strong>2つ目は実績報告の最終締切2027年3月11日です。</strong>ここから逆算します。

1. 実績報告は<strong>工事完了かつ支払が済んだあと</strong>に出す
2. 工事の前に<strong>交付決定</strong>が必要
3. 交付決定までの審査に<strong>約1ヵ月</strong>

したがって、たとえば2027年1月上旬に申請すると、交付決定は2月上旬前後、そこから契約・着工・完工・支払・書類作成をすべて3月11日までに終える必要があります。<strong>工期に余裕がまったくありません。</strong>年度末は解体業者の繁忙期で、産業廃棄物の搬出やアスベスト事前調査の日程も詰まります。

<strong>実務上の安全な申請時期は、秋のうちです。</strong>いま（9月）動き出せば、9月中に見積もり→10月に申請→11月に交付決定→年内着工、という順番で、3月11日まで4か月近い余裕が残ります。

なお、1981年（昭和56年）以前に着工した建物の解体では、石綿（アスベスト）の事前調査結果の報告など、工期に影響する手続きが入ることがあります。手引きにも「解体工事にあたり必要となる届出について」の参考ページがあります。含有の有無で費用も工期も変わるため、見積もり段階で業者に確認してください。相続した建物のアスベスト対応は[アスベスト含有の空き家を相続したときの売却](/guide/asbestos-souzoku-baikyaku)でも解説しています。

## 申請の順番を1回間違えると全額自己負担｜契約は必ず交付決定の後

ここが、この制度でもっとも取り返しがつかない部分です。神戸市は2か所で明記しています。

> 補助金の申請前に解体工事契約や工事着手している場合は対象外です。

> 必ず、補助金の交付決定を受けてから解体業者と契約及び工事の着手を行ってください。補助金の交付決定前に業者と契約や工事の着手を行った場合は補助を受けることができません。

（出典: 神戸市公式ウェブサイト・2026年度申請手引き／2026年9月1日確認）

正しい順番を、番号で固定しておきます。

1. <strong>見積もりを取る</strong>（1社以上必須・2社以上の見積もり合わせを推奨）— ここは契約ではないのでOK
2. <strong>すまいるネットに電話予約</strong>（078-647-9969）
3. <strong>交付申請書を提出</strong>（持参または郵送）
4. <strong>審査（約1ヵ月）</strong>
5. <strong>交付決定通知を受け取る</strong>
6. <strong>ここで初めて解体業者と契約</strong>
7. <strong>工事着手 → 完了 → 支払</strong>
8. <strong>30日以内に実績報告書兼請求書を提出</strong>（最終締切2027年3月11日）
9. <strong>補助金の入金</strong>

<strong>やってしまいがちな失敗が2つあります。</strong>

1つは、<strong>先に契約してから補助金を調べる</strong>ケースです。「解体を頼んだあとで補助金があると知った」というご相談を毎年いただきますが、この制度では救済されません。契約書の日付が交付決定より前なら、それだけで対象外です。

もう1つは、<strong>業者に急かされて契約を先に交わす</strong>ケースです。「補助金の申請はうちがやっておくので、まず契約だけ」と言われたら、その場では押印しないでください。順番を守れば同じ業者でも問題なく使えます。

あわせて、手引きにはこんな注意書きもあります。

> 補助を決定することは、所有権者以外の権利者（抵当権者等）への権利侵害がないことを保証することではありません。抵当権者等がいる場合、抵当権者等へ解体の了承を得るなど、申請者の責任でご対応ください。

<strong>古い住宅ローンの抵当権が登記に残っている空き家は、解体前に抵当権者の了承が必要</strong>ということです。完済しているのに抹消していない抵当権は、相続した実家では珍しくありません。登記事項証明書を取るとき、乙区（権利部）もあわせて確認してください。

神戸市の解体補助で意外と手間取るのが、窓口です。<strong>市役所の窓口ではありません。</strong>

（出典: 神戸市公式ウェブサイト・2026年度申請手引き・すまいるネット／2026年9月1日確認）

![JR新長田駅｜神戸市長田区。すまいるネット（アスタくにづか5番館）の最寄り駅](/images/kobe-akiya-kaitai-hojo-2026-shinnagata.jpg)

<strong>覚えておくと楽になる点を3つ挙げます。</strong>

<strong>1つ目、電話番号が制度ごとに違います。</strong>老朽空家等解体補助は078-647-9969、密集市街地建物除却事業と隣地統合補助は078-647-9933です。どちらを使うか決まっていない段階なら、まず9969にかけて「密集市街地の区域内かどうかも一緒に見てほしい」と伝えるのが早いです。

## 必要書類の全リスト｜相続登記が済んでいない場合・共有名義の場合

手引きが「申請には下記の書類すべての提出が必要」としている必須書類です。

| 書類 | 要点 |
|---|---|
| 補助金交付申請書（様式第1号） | 市ページからWORDでダウンロード |
| 附近見取り図 | 補助対象建物を中心に周辺を示した地図（<strong>縮尺1/1500程度</strong>） |
| <strong>建物の登記事項証明書</strong> | 建築年月・所有者・面積の特定に使う。<strong>発行から3か月以内</strong>のもの（法務局または登記情報提供サービス） |
| 工作物の除却計画書 | 門・塀類、車庫・カーポート、立木竹などについて記載 |
| 現況写真 | 全景（複数枚）＋腐朽・破損箇所1〜2箇所＋（共同住宅は戸数がわかるもの）。<strong>A4カラー印刷</strong> |
| <strong>解体工事見積書の写し</strong> | 1社分必須・<strong>2社以上推奨</strong>。宛名は申請者名／建物の地番または住居表示の記載／申請日時点で見積期限が有効／明細記入 |
| <strong>解体工事業者の建設業許可または解体工事業の登録の写し</strong> | 建設業許可（建築・土木・解体のいずれか）または<strong>兵庫県での解体工事業の登録</strong>。<strong>許可・登録事業者からの見積書でなければ申請の受付ができません</strong> |
| 本人確認書類の写し | 顔写真付き1点、または顔写真なしの場合2点。法人は加えて所属を確認できるもの（名刺・社員証等） |

（出典: 神戸市 2026年度申請手引き／2026年9月1日確認）

<strong>もっとも見落とされるのは、業者の許可・登録の写しです。</strong>「許可・登録事業者からの見積書でなければ、申請の受付ができません」と手引きが明記しています。知り合いの工務店や個人業者に頼む予定の方は、見積依頼と同時に<strong>建設業許可番号または兵庫県の解体工事業登録番号</strong>を確認してください。ここで詰まると、業者選びからやり直しになります。

### 相続登記が済んでいない場合

登記が親名義のままでも申請できます。手引きとQ&Aは、次の書類で代替できるとしています。

- <strong>誓約書</strong>（参考様式）
- <strong>申請者と所有者（被相続人）との関係性を証する書類</strong>: 戸籍謄本、除籍謄本、建物の固定資産課税台帳登録事項証明書、固定資産課税台帳の写し（※3か月以内または申請日が属する年度のもの）
- <strong>所有者（被相続人）が死亡していることを証する書類</strong>: 戸籍謄本、除籍謄本、死亡診断書、住民票

ただし、<strong>複数の相続人がいる場合は相続人全員から解体の同意を得ている必要があります</strong>。ここが実務上いちばん重い条件です。連絡が取れない相続人が1人いるだけで、この補助は使えません。

なお相続登記そのものは2024年4月から義務化されています。期限と過料については[相続登記の義務化｜期限と過料、放置したときのリスク](/guide/inheritance-registry)で解説しています。

### 共有名義の場合

登記名義人が2人以上のときは、<strong>代表者（申請者）以外の所有者からの解体および申請手続きに関する同意書</strong>（参考様式）が必要です。兄弟共有の実家では、まずここを揃えるところから始まります。共有者の意見が割れている場合の出口は[共有持分・共有名義の不動産の売却](/guide/souzoku-mansion-baikyaku)もあわせてご覧ください。

### 売買で取得して所有権移転が未登記の場合

誓約書に加えて、<strong>建物および土地の売買契約書の写し</strong>と<strong>領収書（契約金額全額分）の写し</strong>を提出します。売買契約書だけでは建物の所有権移転が確認できない場合、別途追加書類が必要です。

## 密集市街地なら上限128万円／256万円｜併用できないのでどちらを選ぶか

神戸市には、老朽空家等解体補助よりも金額の大きい制度がもう1つあります。<strong>密集市街地建物除却事業</strong>です。

![神戸市長田区五番町の路地｜密集市街地に残る木造長屋と狭い通路](/images/kobe-akiya-kaitai-hojo-2026-misshu.jpg)

| 項目 | 内容 |
|---|---|
| 対象区域 | 密集市街地再生優先地区＝<strong>灘北西部・兵庫北部・長田南部・東垂水</strong>（2026年度から対象区域が変更） |
| 対象者 | 老朽建物の所有者 |
| 補助金額 | <strong>除却に要する費用の額の3分の2</strong>。上限＝<strong>戸建128万円／集合住宅256万円</strong>、ほか市の定める額など |
| 主な要件 | 除却建物は<strong>1981年（昭和56年）5月31日以前に着工された木造建築物</strong>／除却後に建築する場合は準耐火建築物等以上の耐火性能 |
| 申請期間 | 2026年3月2日〜2027年1月12日（交付決定は2026年4月1日以降・<strong>予算が無くなり次第終了</strong>） |
| 実績報告 | 解体終了後30日以内<strong>または2027年3月10日のいずれか早い日</strong>まで |
| 窓口 | すまいるネット <strong>078-647-9933</strong> |
| 併用 | <strong>老朽空家等解体補助との併用不可</strong> |

（出典: 神戸市公式ウェブサイト／2026年9月1日確認）

<strong>どちらを選ぶかは、解体費の金額で分岐します。</strong>密集市街地建物除却事業は「費用の3分の2」型なので、解体費が大きいほど有利になります。

- 解体費<strong>90万円</strong>のとき: 3分の2＝60万円 → 老朽空家等解体補助（80㎡以上なら60万円）と<strong>ほぼ同じ</strong>
- 解体費<strong>150万円</strong>のとき: 3分の2＝<strong>100万円</strong> → 老朽空家等解体補助の60万円より<strong>40万円多い</strong>
- 解体費<strong>192万円以上</strong>のとき: 3分の2＝128万円 → <strong>戸建の上限128万円に到達</strong>

つまり、<strong>密集市街地再生優先地区の中にあり、1981年5月31日以前に着工した木造建物なら、解体費が90万円を超える時点で密集市街地建物除却事業のほうが大きくなります。</strong>木造戸建の解体費が90万円を下回ることは実際にはあまりないため、区域内・要件該当なら、まず密集市街地側を検討する価値があります。

ただし注意点が2つあります。

<strong>1つ目、上限は128万円だけではありません。</strong>市のページは「上限：戸建128万円、集合住宅256万円、<strong>ほか市の定める額など</strong>」と書いており、さらに2026年度からの変更点として「補助金額のうち、<strong>床面積の合計に乗じる基準額を見直し</strong>」を挙げています。<strong>床面積に基準額を乗じた額でも制限される仕組み</strong>ということです。実額は手引きと窓口の試算で確認してください。「3分の2だから150万円出る」と決め打ちしないことが大事です。

<strong>2つ目、実績報告の締切が1日早いです。</strong>老朽空家側は2027年3月11日、密集市街地側は<strong>2027年3月10日</strong>です。1日の違いですが、年度末の工事では効いてきます。

<strong>自分の空き家が対象区域か</strong>は、市ページの対象区域図（PDF）で確認できます。灘区・兵庫区・長田区・垂水区に空き家がある方は、区域図を先に見てから窓口に電話するのが早道です。

## 六甲山系の物件は上限350万円・補助率10分の10という別枠

もう1つ、神戸市固有の制度があります。他都市にはまず存在しない設計です。

| 項目 | 内容 |
|---|---|
| 制度名 | <strong>六甲山系の老朽家屋等解体補助制度</strong> |
| 補助額 | <strong>1件につき上限350万円（補助率10分の10）</strong> |
| 対象経費 | 老朽家屋又はその他工作物の解体除却工事費用 |
| 対象物件（3点すべて） | ①瀬戸内海国立公園六甲地域（神戸市内）または主要登山道（<strong>布引道・青谷道・上野道・大師道（再度谷）</strong>）沿いから目視で確認できる範囲に存する家屋またはその他工作物 ②腐朽または破損が目視で確認できる ③解体除却により登山者の安心・安全の確保および景観向上になると認められる |

| 窓口 | 経済観光局観光企画課 |

<strong>補助率10分の10、つまり全額です。</strong>上限350万円までなら自己負担なしで解体できる設計になっています。六甲山上の元別荘・元保養所・崩れかけた小屋を相続してしまい、「山の上で搬出費が高く、売るにも壊すにも動けない」という状態の方には、これが最短の出口になり得ます。

ただし対象範囲は限定的です。<strong>登山道沿いから目視で確認できる範囲</strong>という景観要件があり、山中でも見えない場所は原則対象外です。申請期限も<strong>2026年12月11日</strong>と、他の2制度より1か月早く閉じます。該当しそうな物件をお持ちなら、区域図の確認から急いでください。

## 解体費と補助金を差し引きしても手残りはいくらか｜3つの出口を並べる

ここまでが制度の話です。ただ、私たちが日々ご相談を受けていて思うのは、<strong>「補助金がいくら出るか」だけを調べて止まってしまう方が多い</strong>ということです。決めるために必要なのは、<strong>手残りの比較</strong>です。

神戸市内の延べ80㎡・木造2階建て・1975年築の空き家を、<strong>解体費180万円（残置物処分費30万円を含む）／古家付きでの想定売却額900万円／更地での想定売却額1,000万円</strong>と仮定して並べます。

| 選択肢 | 収入 | 支出 | 手残り（税・諸費用前） |
|---|---|---|---|
| A. 放置する | 0円 | 固定資産税・管理費が毎年発生 | <strong>毎年マイナス</strong> |
| B. 解体して更地で売る | 1,000万円 | 解体費180万円 − 補助金60万円＝<strong>実質120万円</strong> | <strong>約880万円</strong> |
| C. 古家付き（現況）で売る | 900万円 | 解体費0円・残置物処分0円 | <strong>約900万円</strong> |

（上記は考え方を示すための仮定の数値です。実際の金額は立地・接道・面積・建物の状態・残置物の量で変わります）

この例では<strong>Cのほうが手残りが多くなります</strong>。理由は単純で、<strong>更地にしても売値が解体費の分だけ上がるとは限らない</strong>からです。60万円の補助が出ても、解体費180万円との差120万円を売値の上昇で回収できなければ、解体は損になります。

逆に<strong>Bが有利になるのは、次のような場合</strong>です。

- 建物が原因で買い手が敬遠されており、<strong>古家付きでは売却自体が進まない</strong>
- 密集市街地建物除却事業が使えて、<strong>補助が100万円以上出る</strong>
- 建物の傷みが進み、<strong>近隣への危険や損害賠償リスクが現実的</strong>になっている
- 特定空家・管理不全空家に指定される可能性があり、<strong>固定資産税の住宅用地特例が外れる見込み</strong>

<strong>大事なのは、この比較を数字で1枚に並べることです。</strong>「補助金が出るなら解体しよう」ではなく、「解体した場合の手残り」と「現況で売った場合の手残り」を2つ出してから決めてください。判断が難しいのは選択肢が多いからではなく、数字が1つしか出ていないからです。

比較の作り方は[空き家の処分方法5つを費用と手残りで比較](/guide/akiya-shobun-5-hikaku)、解体費が用意できない場合の進め方は[相続した実家の解体費用が払えない｜補助金・現況買取で費用ゼロで手放す3つの方法](/guide/akiya-kaitai-hiyou-haraenai)で整理しています。

## 更地にすると固定資産税は上がる｜「壊すか放置か」ではなく「壊すか手放すか」

解体を検討するときに、必ず一緒に確認しておきたいのが固定資産税です。

住宅が建っている土地には<strong>住宅用地の特例</strong>があり、200㎡以下の部分は固定資産税の課税標準が6分の1に軽減されています。<strong>建物を解体して更地にすると、この特例が外れます。</strong>つまり、解体後に土地を持ち続けると、翌年度から土地の固定資産税が上がります。

一方で、放置しておけば安いままとも言えません。空家等対策の推進に関する特別措置法にもとづき、<strong>特定空家等・管理不全空家等として勧告を受けると、同じく住宅用地特例の対象から除外されます</strong>。「壊さなければ6分の1のまま」という前提は、放置が進んだ空き家では崩れます。

この構造を踏まえると、判断軸は<strong>「壊すか放置か」ではなく「壊すか手放すか」</strong>になります。土地を持ち続けるつもりがないなら、解体後に更地の固定資産税を払う期間を作らず、<strong>売却とセットで日程を組む</strong>のが合理的です。

- 固定資産税が上がる条件の詳細: [空き家の固定資産税が6倍になる条件と比較](/guide/akiya-koteishisanzei-6bai-hikaku)
- 指定の判定基準: [特定空家の判定チェックリスト｜指定される前にできること](/guide/tokutei-akiya-hantei-checklist)
- 通知が届いた場合: [管理不全空き家に指定されたときの対処法](/guide/kanri-fuzen-akiya-shitei-taisho)

## 3,000万円特別控除は「自分で解体しなくても」使える（2024年以降の譲渡）

補助金の話をしていると見落とされがちですが、金額の桁が違うのはこちらです。<strong>空き家の譲渡所得の3,000万円特別控除</strong>です。神戸市も「空き家対策等にかかる特別控除」のページで案内しており、税務署に提出する<strong>被相続人居住用家屋等確認申請書</strong>を市が交付します。

<strong>家屋の要件</strong>

- <strong>1981年（昭和56年）5月31日以前に建築</strong>された家屋であること
- 相続開始の直前において、被相続人の居住のために使用し、かつ被相続人以外に居住していた者がいなかったこと（老人ホーム等に入所していた場合も一定要件を満たせば対象）
- 相続の時から譲渡の時まで、<strong>事業、貸付または居住に使用していない</strong>こと

<strong>譲渡する際の要件</strong>

- <strong>相続開始日から3年を経過する日の属する年の12月31日まで</strong>に譲渡すること
- <strong>譲渡価格が1億円以下</strong>であること
- 家屋を譲渡する場合は、譲渡時に現行の耐震基準に適合するか、耐震リフォーム後であること
- 土地を譲渡する場合は、取壊し後であること

そして、実務でいちばん効くのがこの1行です。

> 2024年（令和6年）1月1日以降の譲渡に関しては、譲渡後の当該家屋の耐震改修工事又は取壊しを行う場合でも、譲渡日の属する年の翌年2月15日までに実施すれば対象となります。

（出典: 神戸市公式ウェブサイト／2026年9月1日確認）

<strong>つまり、自分で解体費を払わなくても特別控除を受けられる可能性があります。</strong>買主が引渡し後に解体し、それが翌年2月15日までに終われば要件を満たし得る、という整理です。「補助金60万円のために解体して、そのあと売る」より、「古家付きで売って、解体は買主側で行い、控除は自分が受ける」ほうが手残りが大きくなるケースがあります。

なお、<strong>2024年1月1日以降の譲渡で、家屋または取壊し後の土地等を取得した相続人が3名以上の場合、特別控除額は1人あたり2,000万円</strong>になります。兄弟3人で相続した実家では、1人3,000万円ではありません。

<strong>確認申請書の交付</strong>は、神戸市建築住宅局建築指導部安全対策課（〒651-0083 神戸市中央区浜辺通2丁目1番30号 三宮国際ビル5階）が扱います。申請書と必要書類一式に<strong>切手を貼付した返信用封筒</strong>を添えて提出し、<strong>交付は郵送で2週間程度</strong>かかります。様式は譲渡の内容によって1-1（耐震基準に適合する家屋の譲渡）／1-2（全部取壊し後の譲渡）／1-3（譲渡後〜翌年2月15日までに適合・取壊し）に分かれているため、<strong>売り方を決めてから様式を選ぶ</strong>順番になります。

解体補助の窓口（長田区のすまいるネット）と、この確認申請書の窓口（中央区の安全対策課）は<strong>場所も担当も別</strong>です。両方使う予定なら、日程を分けて組んでください。

制度の全体像は[相続した空き家の3,000万円特別控除](/guide/souzoku-akiya-3000man-tokubetsu-kojo)で詳しく解説しています。適用可否の最終判断は管轄の税務署・税理士にご確認ください。

ここでも順番は同じです。<strong>契約より先に申請</strong>。申請期限も<strong>2026年12月10日</strong>と、解体補助より1か月早く閉じます。

## 神戸市の空き家を市外の宅建業者に相談するとき｜私たちが見ている3つの点

最後に、私たちの立場から正直に書いておきます。空き家のミカタは<strong>大阪・滋賀</strong>を拠点にする宅地建物取引業者で、<strong>神戸市の補助金を代わりに申請することはできません</strong>。補助金の申請代行はすまいるネットで相談してください。

そのうえで、遠方の実家や相続したアパートについてご相談をいただいたとき、私たちが最初に見るのは次の3点です。

<strong>1. 補助金を使うより、現況のまま売るほうが早いケースかどうか</strong>

補助金は上限60万円（共同住宅で100万円）です。一方、解体費は180万円かかることもあります。残置物の処分費も別途必要です。<strong>差額を自分で立て替えて、数か月後に補助金が入る</strong>という資金の流れに耐えられるかを先に確認します。立て替えが難しいなら、古家付きでの売却が現実的な出口です。

<strong>2. 相続人・共有者が揃うかどうか</strong>

神戸市の制度は、<strong>相続人全員の同意</strong>または<strong>共有者全員の同意書</strong>を求めます。ここが揃わない案件は、補助金の入口に立てません。売却であれば、持分の状況に応じた進め方が別にあります。

<strong>3. 建物を残したまま値付けできるかどうか</strong>

現地に行けない方でも、<strong>住所・築年数・延床面積・建物の状態と写真</strong>のやり取りで、古家付き（現況）のまま査定できる場合があります。<strong>解体を前提にしない見積もりを1つ持っておくと、補助金を使う判断の基準ができます。</strong>

神戸市を含む兵庫県内の買取相場の考え方は[神戸市の不動産買取市場2026](/guide/kobe-real-estate-purchase-market-2026)でも整理しています。

## まとめ：神戸市の解体補助金は「面積で決まる定額」と「契約より先に申請」の2点で決まる

- 神戸市老朽空家等解体補助制度の補助額は<strong>登記床面積または課税床面積で決まる定額</strong>。<strong>30㎡未満20万円／80㎡以上60万円</strong>で、工事費の割合ではありません。
- <strong>共同住宅・寄宿舎で100㎡以上かつ3戸以上</strong>なら別表が適用され、<strong>160㎡以上で上限100万円</strong>。判定は現況ではなく<strong>書面の用途の記載</strong>です。
- Q&Aの注記どおり<strong>「補助対象事業費が上限額」</strong>。解体工事費より多い補助は出ません。
- 対象は<strong>1986年（昭和61年）12月31日以前に建てられた腐朽・破損のある空き家</strong>。<strong>住宅以外の用途も対象</strong>、<strong>個人でも法人でも申請可</strong>、<strong>空き家期間の下限なし</strong>、<strong>跡地の使い方の要件なし</strong>。
- <strong>腐朽・破損は屋根・軒庇・外壁・バルコニー・基礎等の5部位のいずれか1か所</strong>で足ります。ただし<strong>ブロック塀・擁壁のひび割れは要件対象外</strong>です。
- 原則、<strong>空き家＋附属建物＋道に面する門塀類＋車庫カーポート＋立木竹まで全部解体</strong>が条件。定額制なので<strong>壊す対象が増えても補助は増えません</strong>。
- <strong>未登記の増築・別棟、1987年1月1日以降に建てられた別棟は面積に算入されません</strong>。それでも解体は必要です。
- 申請は<strong>2026年3月2日〜2027年1月12日</strong>ですが、<strong>予算がなくなり次第終了</strong>。実質の締切は<strong>実績報告の最終期限2027年3月11日</strong>から逆算した日で、<strong>審査に約1ヵ月</strong>かかることを踏まえると<strong>秋のうちの申請が安全</strong>です。
- <strong>交付決定前に解体業者と契約すると1円も出ません。</strong>見積もり→申請→交付決定→契約→着工の順番を崩さないでください。
- <strong>解体業者は建設業許可（建築・土木・解体）または兵庫県の解体工事業登録が必須</strong>。許可・登録のない業者の見積書では受付されません。
- 窓口は市役所ではなく<strong>長田区のすまいるネット（アスタくにづか5番館2階・078-647-9969・10時〜17時・水日祝定休・予約制）</strong>。
- <strong>密集市街地再生優先地区（灘北西部・兵庫北部・長田南部・東垂水）で1981年5月31日以前着工の木造</strong>なら、<strong>費用の3分の2・上限戸建128万円</strong>の密集市街地建物除却事業のほうが大きくなる可能性があります（<strong>併用不可</strong>、解体費90万円が損得の分かれ目）。
- <strong>六甲山系の登山道沿いから見える老朽家屋</strong>は、<strong>補助率10分の10・上限350万円</strong>の別制度があります（申請期限<strong>2026年12月11日</strong>）。
- <strong>更地にすると住宅用地特例が外れて土地の固定資産税が上がります。</strong>ただし勧告を受けた空き家も同じく外れます。「壊すか放置か」ではなく「壊すか手放すか」で考えてください。
- <strong>2024年1月1日以降の譲渡なら、買主が翌年2月15日までに解体しても3,000万円特別控除の対象になり得ます。</strong>自分で解体費を負担せずに税の特例だけを受け取る道があります（相続人3名以上は1人2,000万円）。
- 解体後に狭小地が残るなら、<strong>隣地統合補助（上限50万円・売主も申請可・申請期限2026年12月10日）</strong>が出口になります。
- 迷ったら、<strong>現況のままの査定額</strong>と<strong>更地にした場合の手残り（想定売却額 − 解体費 ＋ 補助金）</strong>を並べてください。数字が2つ並べば、判断は難しくありません。

決めずに置いておくと、固定資産税と管理費を払い続けながら建物の傷みが進み、手放す条件も悪くなっていきます。まずは「今いくらで手放せるか」を確かめることが、いちばん確実な一歩です。査定は無料です。
