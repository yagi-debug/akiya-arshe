## 訳あり物件、どこに相談していいかわからない方へ

「仲介業者に断られた」「相続した物件をどうすればいいかわからない」「買い手がつかなくて何年も放置している」——そんな訳あり物件の処分に困っている方のために、当社は存在しています。

訳あり物件の売却は、通常の不動産売却とは全く異なるノウハウが必要です。**宅地建物取引業者（大阪府知事(1)第65646号）が直接担当**し、最適な買取価格と手続きをご提案します。

## 買取対応している訳あり物件の種類

| 物件種別 | 主な問題 | 当社の対応 |
|---------|---------|---------|
| **再建築不可物件** | 住宅ローン使えない・買い手がいない | 現況買取・接道状況問わず対応 |
| **事故物件（心理的瑕疵）** | 告知義務・買い手が敬遠 | 現況買取・告知事項を踏まえた適正査定 |
| **共有持分** | 他の共有者との折り合いがつかない | 持分のみの買取・全員合意なしでも対応可能なケースあり |
| **相続アパート** | 管理できない・入居者がいる | 入居者付きのまま買取 |
| **空き家・築古物件** | 解体費用が不安・管理が大変 | 現況買取・解体費用負担なし |
| **底地・借地権** | 権利関係が複雑 | 専門知識を持った対応 |

## 買取実績・価格帯の目安

当社は再建築不可・事故物件・共有持分・相続アパートなど、他社で断られやすい訳あり物件の買取を専門にしています。

### 買取価格帯の目安

| 物件種別 | 一般的な買取価格（市場価格比） |
|---------|--------------------------|
| 再建築不可（接道2m未満） | 市場価格の50〜70% |
| 事故物件（告知義務あり） | 市場価格の60〜75% |
| 共有持分（単独） | 市場価格の40〜60% |
| 相続アパート（入居者付き） | 市場価格の70〜85% |
| 空き家（築30年以上） | 市場価格の55〜75% |

> ※上記はあくまで目安です。立地・建物状態・権利関係によって大きく変わります。正確な査定は無料でご確認いただけます。

### 相談から現金化までの流れ

```
相談・無料査定（LINE/電話）
        ↓ 即日〜3日
査定額の提示・条件確認
        ↓ 1〜5日
売買契約の締結
        ↓ 7〜14日（書類が揃っている場合）
決済・引き渡し・現金振込
```

**最短7日、平均21日で現金化**できます。

## なぜ仲介ではなく買取を選ぶのか

### 仲介 vs 買取 — 訳あり物件の場合

| 比較項目 | 仲介 | 当社買取 |
|---------|------|---------|
| 売れる可能性 | 低い（買い手がつきにくい） | **高い（直接買取）** |
| 期間 | 数ヶ月〜数年 | **最短7日** |
| 仲介手数料 | 売却額の3%+6万円 | **不要** |
| リフォーム・清掃 | 必要なことが多い | **現況のまま** |
| 内見・交渉 | 何度も対応が必要 | **不要** |

訳あり物件の場合、仲介で市場に出しても売れないことがほとんどです。「半年待っても買い手がゼロ」「値下げを繰り返して疲弊した」というケースを多く見てきました。
