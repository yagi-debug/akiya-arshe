<strong>相続登記の費用が10万円以上かかると知って、「用意できるか不安」と感じている方へ。</strong>

2024年4月から相続登記が義務化され、「手続きしなければ」と思いながらも費用の壁で動けていない方が増えています。この記事では、費用が払えない場合・期限に間に合わない場合の<strong>実務的な選択肢</strong>を整理してお伝えします。

国土交通省や法務省のサイトには「相続登記の義務化」の概要は載っています。でも「費用が払えない場合にどうするか」という、実際に困っている人が知りたい情報はほとんどありません。この記事では、不動産売却の相談を多数受けてきた宅建業者の立場から、公的機関には載っていない具体的なアクションをお伝えします。

## 相続登記の義務化：まず押さえる3つのポイント

### ①2024年4月1日から義務化

相続登記（不動産の名義変更のこと）は、<strong>2024年4月1日から義務化</strong>されました。相続で不動産を取得したことを知った日から<strong>3年以内</strong>に申請が必要です。

### ②過去の相続も対象・経過措置の期限は2027年3月31日

2024年4月1日より前に発生した相続も対象です。経過措置として、<strong>2027年3月31日</strong>までに相続登記を済ませれば過料の対象になりません。この期限まで残り約2年です。

### ③正当な理由があれば過料は回避できる

「正当な理由なく」期限内に申請しなかった場合、<strong>10万円以下の過料</strong>が科される可能性があります。「正当な理由」として認められる可能性がある状況には以下が含まれます。

| 正当な理由として認められる可能性がある状況 |
|------------------------------------------|
| 相続人が多数で戸籍書類の収集に時間がかかる |
| 遺産分割協議がまとまっていない |
| 重病やそれに準ずる事情がある |
| <strong>経済的に困窮しており登記費用を負担する能力がない</strong> |
| DV被害者で生命・心身に危害が及ぶおそれがある |

費用が払えない状況は、一定の条件下で「正当な理由」として考慮される余地があります。ただし、黙って放置しているだけでは認められません。

## 相続登記の費用の相場：どのくらいかかるのか

<img src="/images/souzoku-touki-hiyou-haraenai-documents.jpg" alt="相続に関する書類と計算機　登記費用の確認イメージ" width="1200" height="800" style="width:100%;height:auto;border-radius:8px;margin-bottom:1.5rem;" />

相続登記の費用は主に2つから構成されます。

### 登録免許税（必須）

相続登記をする際に国に支払う税金です。<strong>固定資産税評価額の0.4%</strong>がかかります。

| 固定資産税評価額 | 登録免許税 |
|--------------|---------|
| 500万円 | <strong>2万円</strong> |
| 1,000万円 | <strong>4万円</strong> |
| 2,000万円 | <strong>8万円</strong> |
| 3,000万円 | <strong>12万円</strong> |

毎年5月ごろに届く固定資産税の課税明細書に評価額が記載されています。土地と建物がある場合は合算した金額で計算します。

### 司法書士への報酬（依頼する場合）

自分で法務局に申請すれば司法書士費用はかかりません。ただし必要書類の収集や申請書の作成に手間がかかります。司法書士に依頼する場合の報酬相場は<strong>5〜12万円程度</strong>（相続の複雑さによって変動）です。

| 手続き方法 | 費用目安（評価額1,000万円の場合） |
|----------|-------------------------------|
| 自分で申請 | 登録免許税4万円＋書類取得1〜2万円＝<strong>計5〜6万円</strong> |
| 司法書士に依頼 | 登録免許税4万円＋報酬5〜12万円＝<strong>計9〜16万円</strong> |

「このお金を今は用意できない」という状況は、決して特別なことではありません。相続が発生したからといって、すぐに数万円〜十数万円を用意できる家庭ばかりではないのが現実です。

## 費用が払えない・間に合わない場合の3つの対処法

### 対処法①：相続人申告登記（実質無料）

<strong>最も手軽で費用がかからない方法</strong>が「相続人申告登記」です。2024年4月に新設されたこの制度は、「私がこの不動産の相続人の一人です」と法務局に申し出るだけで、<strong>暫定的に登記義務を果たしたとみなされます</strong>。

| 項目 | 内容 |
|------|------|
| 申請費用 | 登録免許税なし（<strong>実質無料</strong>） |
| 申請者 | 相続人のうち1人でも単独で可能 |
| 必要書類 | 申出書、自身の戸籍謄本（被相続人の連続戸籍は不要） |
| 効果 | 正式な相続登記の期限まで義務を履行したとみなされる |

ただし、相続人申告登記はあくまで<strong>暫定措置</strong>です。遺産分割が成立したら、その日から3年以内に正式な相続登記を行う必要があります。また、相続人申告登記だけでは不動産の売却はできません。「とにかく過料リスクだけ先に回避したい」という場合に有効な選択肢です。

### 対処法②：法テラス（日本司法支援センター）の利用

収入・財産が一定基準以下の方は、<strong>法テラスの審査書類立替制度</strong>を利用できる場合があります。司法書士報酬を法テラスが立て替え、分割で返済する仕組みです。

ただし、審査に時間がかかること、立替額に上限があること、資力基準を満たす必要があることに注意が必要です。急いで対処したい場合は次の選択肢の方が現実的かもしれません。

### 対処法③：不動産を買取に出す（最も確実）

費用面・スピード面で最も確実な解決策が、<strong>不動産を買取業者に売却すること</strong>です。

買取を選ぶ場合、相続登記の手続きは売却プロセスの中で自動的に行われます。<strong>手元に登記費用がなくても、売却代金から登録免許税と司法書士費用を充当するため、追加の出費が不要</strong>なケースがほとんどです。

## 買取で解決できる理由：費用面の具体的なメリット

<img src="/images/souzoku-touki-hiyou-haraenai-consultation.jpg" alt="不動産の買取相談をしている場面のイメージ" width="1200" height="800" style="width:100%;height:auto;border-radius:8px;margin-bottom:1.5rem;" />

「登記してから売る」と「買取で一括解決する」の違いを整理します。

### パターンA：登記してから売る場合

1. 司法書士に相続登記を依頼（費用：登録免許税＋報酬で計9〜16万円を先払い）
2. 登記完了後、不動産会社に売却依頼
3. 買主が見つかれば契約・引き渡し（時間：3ヶ月〜1年以上かかることもある）
4. 仲介手数料を支払い（売却価格の3%＋6万円＋消費税）

**費用の流れ：まず登記費用を先払い → 売却後に仲介手数料を支払い**

### パターンB：買取業者に直接売る場合

1. 買取業者に相談（現状のまま、登記未完了でもOK）
2. 買取価格の提示を受ける
3. 相続登記の手続きを司法書士が代行（費用は売却代金から）
4. 売買契約締結・決済・引き渡し（時間：最短2〜4週間）

**費用の流れ：登記費用の先払い不要 → 売却代金から一括精算**

| 比較項目 | 登記してから売る | 買取で一括解決 |
|---------|--------------|-------------|
| 登記費用の先払い | <strong>必要</strong>（9〜16万円） | <strong>不要</strong>（売却代金から） |
| 売却完了までの時間 | 3ヶ月〜1年以上 | <strong>最短2〜4週間</strong> |
| 仲介手数料 | かかる | <strong>不要</strong>（直接買取） |
| 登記未完了でも相談可 | 原則不可 | <strong>可能</strong> |

## 期限が近い場合は早めに動く理由

2027年3月31日の経過措置期限が近づくと、同じ状況の相続人が一斉に動き始めることが予想されます。

- 司法書士事務所への依頼が集中し、<strong>手続きに数ヶ月待ちが発生する可能性</strong>
- 売却希望者が増えることで<strong>買取価格に影響</strong>が出る可能性
- 相続登記を放置している期間に相続人が亡くなると「数次相続」が発生し、手続きがさらに複雑になる

費用が払えない状況だからといって、ただ放置することが一番のリスクです。<strong>費用をかけずに動ける選択肢（相続人申告登記・買取）を早めに活用することが、長期的な損失を防ぐことにつながります。</strong>

## よくある質問

<strong>Q. 相続人が複数いる場合、1人でも相続人申告登記はできますか？</strong>

相続人申告登記は相続人の1人が単独で申し出られる制度です。他の相続人全員の同意は不要です。申請後、他の相続人が別々に申し出ることもできます。

<strong>Q. 不動産の価値が低く、登記費用の方が高くなりそうです。どうすればいいですか？</strong>

固定資産税評価額が100万円以下の場合、登録免許税は4,000円と非常に安くなります。一方で不動産の実態価値が低く、司法書士費用が売却益を上回るようなケースでは、買取業者に一括で相談することで費用の最適化が図れる場合があります。状況によっては相続土地国庫帰属制度（国への返還）も選択肢のひとつです。

<strong>Q. 遺産分割がまとまらず、費用分担でも揉めています。どうすれば？</strong>

遺産分割協議がまとまらない場合、まず相続人申告登記で過料リスクだけ回避してください。費用分担の問題は家庭裁判所の調停で解決する方法があります。また、共有持分のみを買取業者に売却することも選択肢のひとつです。共有持分であれば、他の相続人の同意なしに自分の持分だけを売ることができます。

<strong>Q. 登記費用を売却代金から充当する場合、手元に残るお金は減りますか？</strong>

はい、登録免許税と司法書士費用（合計9〜16万円程度）は売却代金から差し引かれます。ただし買取業者への直接売却では仲介手数料（通常3%超）がかかりません。トータルでの費用負担は仲介売却より抑えられるケースが多いです。

| 状況 | 推奨する選択肢 |
|------|-------------|
| とにかく過料リスクだけ先に回避したい | <strong>相続人申告登記</strong>（実質無料） |
