不動産の相談を始めようとして、「何から話せばいいのかわからない」「調べてからでないと失礼ではないか」と止まってしまう方がいらっしゃいます。<strong>最初の相談で必要なのは、物件の市区町村・入居状況・売却を考える理由を、わかる範囲で伝えることだけです。</strong>

この記事では、最初に伝える内容を1枚にまとめた確認表を用意しました。8つの項目を、<strong>「不明」「未定」のままでも書き出せる形</strong>にしています。印刷しても、画面を見ながらメモに書き写しても構いません。

## 相談を始める前の確認表（記入欄）

次の8項目が、最初の相談で伝える内容です。右の欄に、ご自身の状況を書き出してください。

| 確認すること | 自分の状況を書く欄 |
|---|---|
| 物件の所在地 | 府県：　　市区町村：　　|
| 物件の種類 | 一戸建て／アパート一棟／区分マンション／土地／その他／不明 |
| 入居状況 | 入居中／一部入居／空室／不明 |
| 困っていること | 管理／修繕／相続関係／費用／その他：　　|
| 売却を考える時期 | 未定／希望時期：　　／期限がある理由：　　|
| 手元にある情報 | 所在地・名義がわかる資料／入居状況／家賃の明細／その他／資料なし |
| 現地確認について伝えたいこと | 鍵の所在：わかる・不明　／　現地で対応できる人：いる・いない・未確認 |
| 相談して確認したいこと | 机上でどこまで確認できるか／必要な追加情報／現地確認の進め方／その他：　　|

<strong>記入しにくい欄は、不明・未定で構いません。</strong>空欄が多いことは、相談を始められない理由にはなりません。

## 8つの項目に、それぞれ何を書くか

![机の上に広げた不動産の書類を確認しながら記入する様子](/images/soudan-hajimeru-kakunin-hyo-h2-1.jpg)

### 1. 物件の所在地

府県と市区町村までで構いません。番地まで正確に書けなくても、話を始めることはできます。所在地は、対応できる地域かどうかを最初に確かめる項目でもあります。<strong>空き家のミカタがご相談をお受けしているのは、物件の所在地が大阪・兵庫・京都・奈良・滋賀・和歌山の不動産です。</strong>所有者の方がどこにお住まいかは問いません。

### 2. 物件の種類

一戸建て・アパート一棟・区分マンション・土地のどれかを選んでください。登記上の種類と実際の使われ方が違うことはよくあります。判断がつかないときは「不明」で構いません。

### 3. 入居状況

入居中・一部入居・空室のどれかです。アパート一棟の場合、「何戸のうち何戸が埋まっているか」がわかれば、その数字も添えてください。最後に確認したのが何年も前であれば、「以前は空室だったが現在は不明」と書いていただければ十分です。

### 4. 困っていること

管理・修繕・相続関係・費用のどれに近いかを選び、具体的に書けることがあれば一言添えてください。ここは<strong>相談の出発点になる項目</strong>です。「遠方で様子を見に行けない」「修繕の見積もりが高かった」「固定資産税だけ払い続けている」など、今いちばん負担に感じていることをそのまま書いてください。

### 5. 売却を考える時期

未定で構いません。未定と書くことが、相談を後回しにする理由にはなりません。<strong>期限がある場合は、その理由まで書いてください。</strong>相続の手続きや、支払いの予定など、理由によって進め方の順番が変わります。

### 6. 手元にある情報

所在地・名義がわかる資料、入居状況、家賃の明細などのうち、今すぐ見られるものに印を付けてください。<strong>「資料なし」も選択肢のひとつです。</strong>資料をそろえてから相談しようとすると、それだけで何か月も止まってしまうことがあります。

### 7. 現地確認について伝えたいこと

鍵の所在がわかるか、現地で対応できる人がいるかの2点です。どちらも「不明」「未確認」で構いません。これは<strong>現地確認の進め方を決めるための情報</strong>であり、用意できていないと相談できないという条件ではありません。

### 8. 相談して確認したいこと

机上でどこまで確認できるか、追加で必要な情報は何か、現地確認をどう進めるか。聞きたいことが決まっていれば書いてください。決まっていなければ、この欄も空欄のままで構いません。

## 「不明」「未定」のままで相談できます

確認表を見て、空欄の多さが気になった方もいらっしゃるかもしれません。ここは誤解されやすいところなので、はっきりお伝えします。

<strong>空欄は、相談を断る理由になりません。</strong>不動産の相談では、所有者の方が全部を把握していないほうが普通です。相続で引き継いだ物件であれば、なおさらです。

| よくあるお気持ち | 実際のところ |
|---|---|
| 資料がそろってから相談しないと失礼だ | 資料がそろうまで待つ必要はありません。「資料なし」から始められます |
| 物件を見ていないので話せることがない | 所在地と、わかる範囲の状況があれば話を始められます |
| 兄弟と話がついていないので早い | 何ができるかを知ってから家族で話すほうが、判断の材料がそろいます |
| 鍵がないので査定してもらえない | 鍵の状況は現地確認の進め方を決める情報です。相談自体は始められます |

先に費用をかけて片づけたり、調べ直したりする前にご相談いただくほうが、結果として負担が軽くなることがあります。

片づけの費用と手残りの関係は<a href="/guide/katazukenaide-soudan">片付けないでご相談ください</a>にまとめています。

相続の段階ごとの考え方は<a href="/guide/soudan-shiteii-joutai-checklist">相続した家、まだ相談していい？</a>にまとめています。

## この確認表に書かなくてよいこと

![この確認表に書かなくてよいこと - 空き家のミカタ](/images/soudan-hajimeru-kakunin-hyo-h2-2.jpg)

確認表は、物件と状況を整理するためのものです。次のものを書く必要はありません。

- <strong>氏名・連絡先</strong>（連絡の方法は、ご相談の中でお伺いします）
- <strong>口座番号・身分証明書の内容</strong>
- <strong>他社に伝えた金額や、他社との経緯</strong>（必要になれば相談の中で伺います）

手元のメモとして書き出しておき、そのうち伝えられる範囲だけをお送りいただく形で構いません。

## 確認表を書いたあと、相談で確かめること

記入欄がひととおり埋まったら、次は<strong>相手に聞く番</strong>です。相談のときに確かめておくと、そのあとの進め方が見えやすくなります。

1. <strong>今の情報で、どこまで確認できるか</strong> — 現地を見る前の段階で何がわかり、何が仮の前提になるのか
2. <strong>追加で必要な情報は何か</strong> — 資料なのか、現地で見る項目なのか
3. <strong>現地確認をどう進めるか</strong> — 立ち会いが必要か、鍵がない場合どうするか
4. <strong>相談・査定に費用がかかるか</strong> — 空き家のミカタでは相談・査定は無料です

現地確認前に何がわかるかは<a href="/guide/kijou-satei-souzoku-fudosan-soudan">机上査定の記事</a>にまとめています。

鍵や立会いの段取りは<a href="/guide/kagi-genchi-tachiai-soudan-jyunbi">鍵がない場合の相談準備</a>にまとめています。

金額を提示されたあとの検討は<a href="/guide/teiji-kakaku-kento-jyunbi">提示された査定額の検討</a>にまとめています。

なお、税金の取り扱いは税理士、登記の手続きは司法書士へご確認ください。

## よくあるご質問

![よくあるご質問 - 空き家のミカタ](/images/soudan-hajimeru-kakunin-hyo-h2-3.jpg)

<strong>Q. 確認表に空欄があっても相談できますか？</strong>
できます。記入しにくい欄は「不明」「未定」のままで構いません。最初に必要なのは、物件の市区町村・入居状況・売却を考える理由を、わかる範囲で伝えることです。資料がそろうまで相談を待つ必要はありません。空欄の部分は、相談の中で一緒に確認していきます。

<strong>Q. 物件を見に行っていないのですが、所在地だけで相談できますか？</strong>
所在地と手元の情報から、現地を確認する前の段階でお話しできることがあります。ただし机上で出せるのは見当であり、建物の傷みや荷物の量など、現地で確認する項目しだいで変わります。何が机上でわかり、何が仮の前提になるかは机上査定の記事にまとめています。

<strong>Q. 鍵が見つからず、現地で立ち会える人もいません。確認表にはどう書けばよいですか？</strong>
「現地確認について伝えたいこと」の欄に、鍵の所在は不明、現地で対応できる人はいない、とそのまま書いてください。鍵や立会いの状況は、現地確認の進め方を決めるための情報です。この段階で用意できていなくても、相談を始めることはできます。

<strong>Q. 建物の傷みや設備の状態がわかりません。調べてから相談すべきでしょうか？</strong>
調べてからでなくて構いません。設備や建物の状態は現地で確認する項目です。今わかっている範囲で「困っていること」の欄に書いてください。たとえば水回りの不具合を聞いている、長く人が住んでいない、といった内容で十分です。

<strong>Q. 氏名や連絡先も、この確認表に書くのですか？</strong>
この確認表は、物件と状況を整理するためのものです。氏名・連絡先・口座番号・身分証明書の内容を書く必要はありません。連絡の方法はご相談の中でお伺いします。

- 最初の相談で伝えるのは、<strong>市区町村・入居状況・売却を考える理由</strong>を、わかる範囲で、の3点から始められます。
