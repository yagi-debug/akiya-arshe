<strong>この記事の結論</strong><br>
相続した家の選択肢は「住む・貸す・売る・放置」の4択。<strong>5年間コストで比較すると「今すぐ売る」が最大手取り</strong>になるケースが多い。「放置」は表面上コストが低く見えるが、建物価値の低下と相続空き家3,000万円特別控除（3年期限）の逸失で今すぐ仲介売却より250万円以上損するリスクがある。築古・訳あり・急ぎなら直接買取（最短2週間・仲介手数料ゼロ）、状態が良ければ仲介売却（手取り最大化）。空き家のミカタ（宅建業者・大阪府知事(1)第65646号）が全国対応・無料査定。

<strong>Q: 相続した家はどうすればいいですか？住む・貸す・売る・放置のどれが得ですか？</strong>
A: 5年間コストで比較すると「今すぐ仲介売却」が最大手取り（試算例：約1,246万円）。次いで「住む」（家賃節約効果込みで実質プラス）、「貸す」（5年純収益約116万円）、「放置→5年後売却」（今すぐより250万円損）の順。相続から3年以内なら3,000万円特別控除が使え、多くのケースで譲渡税がゼロになる。

<strong>「相続した家をどうすればいいか」</strong> — この問いへの答えは、あなたの状況と物件の条件によって変わります。ただし、感覚ではなく<strong>具体的なコストと収益の数字</strong>で比較すれば、答えは見えてきます。

この記事では、フローチャートで状況を整理したあと、「住む・貸す・売る・放置」の4択それぞれについて<strong>5年間の具体的なコスト試算</strong>を示します。試算の前提条件は「築35年の木造一戸建て、固定資産税評価額900万円、市場価格（仲介売却想定）1,300万円」です。ご自身の物件の数字に置き換えて参考にしてください。

<strong>試算の前提条件（参考例）</strong>

| 市場価格（仲介売却想定） | 1,300万円 |
| 直接買取価格（現況） | 950万円 |

### ① 住む：5年間のコスト試算

自分または家族が引越して居住する選択肢です。

| コスト項目 | 金額（目安） |
|-----------|------------|
| <strong>初期リフォーム費</strong>（居住水準に改修） | 200〜300万円 |
| 固定資産税（土地1/6軽減・年約5万円×5年） | 25万円 |
| 火災保険料（年3万円×5年） | 15万円 |
| 維持・修繕費（年10万円×5年） | 50万円 |
| <strong>5年間の合計コスト</strong> | <strong>290〜390万円</strong> |

<strong>節約効果：</strong>
月8万円の家賃を払っていた場合、5年間で480万円の住居費を節約できます。リフォームコストを差し引いても<strong>実質90〜190万円のプラス</strong>になる計算です。

<strong>向いている人：</strong>
- 現在の住居より条件が良い（立地・広さ・家賃）
- 引越しが可能な状況にある
- 物件が居住可能な状態（または合理的なリフォーム費で整備できる）

<strong>注意点：</strong>
築古物件のリフォームは見積もりより高額になることがあります。特に耐震補強・給排水設備の更新・断熱改修が必要な場合は500万円以上になるケースもあります。居住前に建物診断（ホームインスペクション）を受けることをおすすめします。

→ 詳細は<a href="/guide/souzoku-ie-doushitara">「相続した家をどうする？」全体ガイド</a>をご覧ください。

### ② 貸す：5年間の収支試算

物件を賃貸に出して家賃収入を得る選択肢です。

| 収支項目 | 金額（目安） |
|---------|------------|
| <strong>初期リフォーム費</strong>（賃貸仕様に改装） | 100〜200万円 |
| 年間家賃収入（月6万円×12ヶ月） | 72万円/年 |
| 管理委託費（家賃の8%） | ▲5.8万円/年 |
| 固定資産税（年約5万円） | ▲5万円/年 |
| 修繕費・空室損（20%想定） | ▲8万円/年 |
| <strong>年間純収益（概算）</strong> | <strong>約53万円/年</strong> |
| 5年間純収益 | 265万円 |
| 初期リフォーム費差引後 | <strong>約65〜165万円の利益</strong> |

<strong>向いている人：</strong>
- 最寄り駅から徒歩15分以内など賃貸需要がある立地
- 物件を手放さずに収入を得たい
- 管理会社に委託できる状況にある

<strong>注意点：</strong>
築35年以上の木造一戸建ては入居者付けが難しいことがあります。また、修繕が重なると収益が急減します。賃貸を選ぶ場合は、入居付けの見込みを地元の不動産会社に事前確認してください。賃貸活用後に売却する場合、<strong>売却タイミングが相続から3年を超えると3,000万円特別控除が使えなくなる</strong>点にも注意が必要です。

→ 詳細は<a href="/guide/souzoku-apart-kanri-dekinai-houchi-cost">「相続アパートの維持コストと管理」</a>もあわせてご覧ください。

### ③ 今すぐ売る（直接買取）：手取り試算

訳あり・急ぎの場合に最適な選択肢です。

| 項目 | 金額（目安） |
|------|------------|
| 直接買取価格（現況・仲介手数料ゼロ） | 950万円 |
| 相続登記費用（司法書士報酬含む） | ▲8万円 |
| その他費用 | ▲数万円 |
| <strong>手取り額（目安）</strong> | <strong>約937万円（最短2週間で現金化）</strong> |
| 相続空き家特別控除（3,000万円）適用後の譲渡税 | ほぼゼロ（要件充足の場合） |

<strong>向いている人：</strong>
- できるだけ早く現金化したい
- 築古・再建築不可・共有持分など仲介で売りにくい訳あり物件
- 遠方に住んでいて管理が難しい
- 相続人が複数いて早期解決したい

<strong>買取のメリット：</strong>
現況のまま（片付け・修繕不要）、仲介手数料ゼロ、最短2週間で決済。仲介の「手取り最大化」と比較すると価格は下がりますが、時間・手間・リスクを最小化できます。

→ 詳細は<a href="/guide/wakeare-bukken-kaitori">「訳あり物件の買取ガイド」</a>をご覧ください。

### ④ 今すぐ売る（仲介売却）：手取り試算

急がず手取り最大化を狙う場合に適した選択肢です。

| 項目 | 金額（目安） |
|------|------------|
| 仲介売却価格 | 1,300万円 |
| 仲介手数料（3%+6万円＋消費税） | ▲46万円 |
| 相続登記費用 | ▲8万円 |
| <strong>手取り額（目安）</strong> | <strong>約1,246万円（3〜6ヶ月後）</strong> |
| 相続空き家特別控除（3,000万円）適用後の譲渡税 | ほぼゼロ（要件充足の場合） |

<strong>向いている人：</strong>
- 急いでいない（3〜6ヶ月待てる）
- 物件の状態が比較的良く、買い手が付きやすい
- 立地が良く市場価格での売却が見込める

<strong>注意点：</strong>
訳あり要素（築古・再建築不可・残置物・共有名義など）があると、仲介で売れるまで半年以上かかることがあります。その間の管理費・固定資産税も発生します。

→ 詳細は<a href="/guide/inheritance-sale">「相続した不動産を売却する完全ガイド」</a>をご覧ください。

### ⑤ 放置する：5年間のコスト（非推奨）

「とりあえず何もしない」選択肢。コストと機会損失が積み重なります。

| コスト項目 | 金額（目安） |
|-----------|------------|
| 固定資産税（年約5万円×5年） | 25万円 |
| 最低限の管理費（年5万円×5年） | 25万円 |
| <strong>5年間の合計維持コスト</strong> | <strong>50万円</strong> |
| 5年後売却価格（建物価値低下を想定） | 1,100万円 |
| 5年後仲介売却の手取り | 1,046万円 |
| <strong>実質手取り（維持コスト差引）</strong> | <strong>996万円</strong> |

<strong>今すぐ仲介売却（①）との比較：</strong>

| 選択肢 | 5年間実質手取り |
|--------|--------------|
| 今すぐ仲介売却 | 約1,246万円 |
| 5年放置→売却 | 約996万円 |
| <strong>差額（損失）</strong> | <strong>▲約250万円</strong> |

<strong>放置が最もリスクが高い3つの理由：</strong>

1. <strong>相続空き家3,000万円特別控除の期限</strong>：相続開始から3年を経過する年の12月31日まで。放置すると期限を逃し、譲渡所得税（利益の20〜39%）が発生する可能性があります。
2. <strong>建物の老朽化加速</strong>：空き家は人が住んでいる家より劣化が速い。雨漏り・シロアリ・設備の腐食が進み、5年後には売却価格がさらに下がるリスクがあります。
3. <strong>特定空き家指定のリスク</strong>：管理不全と判断されると固定資産税が最大6倍になります（住宅用地特例の解除）。2023年の法改正で「管理不全空き家」も対象になりました。

→ 放置リスクの詳細は<a href="/guide/akiya-koteishisanzei-6bai-hikaku">「空き家固定資産税6倍化の回避策」</a>をご覧ください。

## 節税の分岐点：相続から3年以内かを確認する

どの選択肢を選ぶにしても、<strong>相続開始からの経過期間</strong>によって税金が大きく変わります。

<div style="background:#fef2f2;border-left:4px solid #dc2626;padding:1rem 1.5rem;margin:1.5rem 0;border-radius:4px;">
<strong>相続空き家3,000万円特別控除の期限</strong><br>
被相続人が居住していた空き家（昭和56年5月31日以前築は耐震改修または除却が必要）を売却した場合、一定要件を満たせば譲渡所得から3,000万円（相続人3人以上の場合は2,000万円）を控除できます。<br>
<strong>期限：相続開始日から3年を経過する日が属する年の12月31日まで</strong><br>
この期限を過ぎると控除が使えず、譲渡益の20〜39%の税金が発生します。
</div>

| 相続からの経過期間 | 3,000万円特別控除 | 取得費加算の特例 |
|-----------------|----------------|--------------|
| <strong>3ヶ月以内</strong> | 使える（申告期限10ヶ月以内） | 使える |
| <strong>3年以内</strong> | 使える | 使える（申告期限から3年以内） |
| <strong>3年超</strong> | 使えない | 使えない |

相続から3年以上経過している場合でも売却は可能ですが、節税メリットが大きく減ります。<strong>現在どの段階にいるかを確認することが最初の一歩</strong>です。

→ 節税の詳細は<a href="/guide/souzoku-akiya-3000man-tokubetsu-kojo">「相続空き家の3,000万円特別控除」完全ガイド</a>をご覧ください。

## よくある質問

### Q. 相続登記（名義変更）をしていないと選択できない選択肢はありますか？

A. 売却（仲介・買取とも）の正式契約には相続登記の完了が必要です。ただし、<strong>査定・相談は登記前でも可能</strong>です。当社では司法書士との連携で登記手続きと売却を並行して進めるサポートも行っています。なお、2024年4月から相続登記は義務化されており、相続を知った日から3年以内に申請しないと10万円以下の過料が科されます。

→ <a href="/guide/inheritance-registry">「相続登記の義務化ガイド」</a>も参照してください。

### Q. 相続人が複数いる場合、全員が合意しないと何も決められませんか？

A. 売却には原則として<strong>相続人全員の同意</strong>が必要です（遺産分割協議書に全員の署名・押印）。意見がまとまらない場合は家庭裁判所での調停・審判という手続きもあります。共有持分だけを売却することも法律上は可能です（他の相続人の同意不要）が、共有持分のみの買取は市場価格より大幅に低くなることがほとんどです。

### Q. 訳あり物件（再建築不可・事故物件など）でも選択肢はありますか？

A. あります。直接買取なら、再建築不可・事故物件・築古・残置物あり・共有名義など、どのような訳あり要素があっても現況のまま買取できます。仲介で売れない物件でも対応可能です。まずは無料査定からご相談ください。

### Q. フローチャートで「貸す」を選んだが、やはり後で売りたい場合は？

A. 賃貸に出した後でも売却は可能です（入居者がいる場合はオーナーチェンジ売却または立退き交渉）。ただし、<strong>賃貸活用中に相続から3年以上経過すると3,000万円特別控除の期限が切れる</strong>可能性があります。賃貸を選ぶ場合は、この期限を意識したうえで判断することをおすすめします。
