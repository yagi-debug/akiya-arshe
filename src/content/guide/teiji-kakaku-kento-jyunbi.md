<strong>査定額や買取の提示額を受け取ったあと、その場で返事をする必要はありません。</strong>検討する間にやっておきたいことは、次の3つです。

1. <strong>金額の前提を確かめる</strong>（どの段階の数字か・何が含まれているか）
2. <strong>自分が伝えた情報にずれがないか見直す</strong>
3. <strong>決めるための期限と、同意が必要な人を整理する</strong>

査定額がどう決まるのか、机上査定で何がわかるのかは別の記事で説明しています。この記事は「金額を受け取ったあと、検討している間」に絞り、相談で使える確認表をまとめました。

---

## 提示された金額が「どの段階の数字か」を最初に確かめる

同じ「査定額」という言葉でも、どこまで確認したうえでの数字かによって、あとから動く可能性が違います。

| 段階 | どんな数字か | あとから動く可能性 |
|---|---|---|
| 机上の見当 | 所在地や手元の情報、公的な情報から出した価格の見当 | 建物の傷みや荷物の量など、現地で確認する項目しだいで動く |
| 現地確認後の提示 | 現地で建物・土地の状態を見たうえで出した金額 | 境界や権利関係など、まだ確認していない項目があれば動くことがある |
| 契約書に書かれた売買代金 | 売主と買主が合意して契約した金額 | 契約の内容にしたがって扱われる |

<strong>売買の代金が決まるのは、契約を結んだときです。</strong>査定額や提示額は、その手前の段階の数字です。受け取った金額がどの段階のものか、はっきり書かれていない場合は、まずそこを聞いてください。

机上査定の段階で何がわかり、何が仮の前提になるかは<a href="/guide/kijou-satei-souzoku-fudosan-soudan">机上査定とは？空き家・訳あり物件を現地確認前に相談する方法</a>にまとめています。

### 仲介と直接買取で、提示額の意味が違います

不動産会社に<strong>売却の仲介</strong>を頼む場合、会社が示すのは「この価格なら売れそう」という見込みです。宅地建物取引業法では、仲介の契約をした会社が売り出す価格について意見を述べるときは、<strong>その根拠を明らかにしなければならない</strong>と定められています（第34条の2第2項）。

一方、<strong>会社が買主として直接買い取る</strong>場合の提示額は、その会社自身が買う金額の提案です。仲介のこの条文の場面とは異なりますが、どちらの場合でも「何を前提にこの金額なのか」を聞くことはできます。仲介と買取の違いは<a href="/guide/osaka-kaitori-vs-chukai">不動産売却は買取・仲介・放置どれが正解？</a>をご覧ください。

## 検討中に確かめたい「金額の前提」

![提示額を検討するときの確認表 - 空き家のミカタ](/images/teiji-kakaku-kento-jyunbi-h2-1.jpg)

提示額は、いくつかの前提の上に成り立っています。検討中に、次の項目を相手に確認しておくと、あとで「思っていた条件と違った」となりにくくなります。

| 確認すること | 確認する理由 | 聞き方の例 |
|---|---|---|
| 建物の状態をどう見ているか | 傷みを見込んでいるかどうかで、現地確認後に動く幅が変わる | 「建物の状態は、どういう前提で金額を出していますか」 |
| 室内に残っている荷物の扱い | 処分を売主がするのか、買主が引き受けるのかで手元に残る金額が変わる | 「荷物はこのままで引き渡してよいですか。処分費用は含まれていますか」 |
| 入居者の扱い（アパート・貸家の場合） | 入居中のまま引き継ぐ前提か、空室にしてからの前提かで条件が変わる | 「入居者がいる状態のままでの金額ですか」 |
| 測量・解体などの費用を誰が負担するか | 売主の負担が増えると、同じ提示額でも手元に残る金額が減る | 「売主が負担する費用はありますか。あれば項目と目安を教えてください」 |
| 引渡し後に不具合が見つかった場合の扱い | 契約で売主の責任をどう定めるかで、引渡し後の心配の大きさが変わる | 「引渡し後の不具合について、売主の責任はどう扱う予定ですか」 |
| 引渡しの時期 | 売却を考える時期や期限と合っているかを確かめる | 「契約から引渡しまで、どのくらいの期間を想定していますか」 |
| 今後、金額が変わる可能性がある項目 | まだ確認していない項目が残っていれば、その結果で金額が動く | 「この金額から変わる可能性があるのは、どの項目ですか」 |
| 提示額の有効期限 | 検討の予定を立てるため | 「いつまでに返事をすればよいですか」 |

聞いた答えは、日付と一緒にメモしておくと、他社と比べるときや家族に説明するときに役立ちます。

### 他社と比べるときは「手元に残る金額」でそろえる

複数の会社から提示を受けた場合、金額の数字だけで比べると判断を誤りやすくなります。上の表の「荷物の扱い」「費用の負担」「引渡し後の不具合の扱い」「引渡しの時期」をそろえて比べてください。

買取価格が仲介の売り出し価格より低くなる理由や、買う側が負担する費用の考え方は<a href="/guide/kaitori-kakaku-naze-yasui-genka">買取価格はなぜ仲介より安いのか</a>で説明しています。

## 自分が伝えた情報に、ずれがないか見直す

提示額は、<strong>所有者の方から伝わった情報</strong>を前提にしています。査定を頼んだときに「不明」「未定」と伝えた項目が、その後わかることもあります。検討中に、次の確認表で見直してみてください。

| 確認すること | 査定を頼んだときに伝えた内容 | 今わかっていること |
|---|---|---|
| 物件の所在地 | 府県：　市区町村：　 | |
| 物件の種類 | 一戸建て／アパート一棟／区分マンション／土地／その他／不明 | |
| 入居状況 | 入居中／一部入居／空室／不明 | |
| 困っていること | 管理／修繕／相続関係／費用／その他：　 | |
| 売却を考える時期 | 未定／希望時期：　／期限がある理由：　 | |
| 手元にある情報 | 所在地・名義がわかる資料／入居状況／家賃の明細／その他／資料なし | |
| 現地確認について伝えたいこと | 鍵の所在：わかる・不明／現地で対応できる人：いる・いない・未確認 | |
| 相談して確認したいこと | 机上でどこまで確認できるか／必要な追加情報／現地確認の進め方／その他：　 | |

<strong>記入しにくい欄は「不明」「未定」のままで構いません。</strong>この表に氏名・連絡先・口座番号・身分証明書を書く必要はありません。

「伝えた内容」と「今わかっていること」が違う欄があれば、検討中に相手へ伝えてください。前提が変われば、金額や条件が見直されることがあります。見直しで金額が上がるか下がるかは、内容によって異なります。

### 伝えていない不具合や出来事は、契約の前に伝える

売買の契約で「売主は引渡し後の不具合の責任を負わない」という特約を結んだ場合でも、民法では、<strong>売主が知りながら告げなかった事実</strong>については責任を免れることができないと定められています（第572条）。

建物の不具合や、建物の中で過去に起きた出来事など、知っていて伝えていないことがあれば、検討中のうちに伝えておくほうが、あとで困りにくくなります。言いにくい内容の場合は、まず「伝えておきたいことがある」とだけ伝えていただいても構いません。建物内の出来事をどこまで伝えるかは<a href="/guide/shinriteki-kashi-kokuchi-gimu">心理的瑕疵とは？事故物件の告知義務の範囲</a>をご覧ください。

## 決めるための「期限」と「同意が必要な人」を整理する

提示額に納得できるかどうかとは別に、<strong>いつまでに、誰の同意で決めるのか</strong>を整理しておくと、検討が止まりにくくなります。

- <strong>提示額の有効期限</strong>：いつまでに返事が必要か、期限を過ぎたらどうなるか
- <strong>ご自身の期限</strong>：売却を考える時期に期限がある場合、その理由（管理の負担、費用の支払い、話し合いの予定など）
- <strong>同意が必要な人</strong>：名義が共有になっている、相続の話し合いがまだ終わっていないなど、ご自身だけで決められない場合は、誰の同意が必要か

ご家族や他の相続人に相談する場合は、この記事の「金額の前提」の表で確認した答えを一緒に見せると、金額の数字だけが独り歩きしにくくなります。相続の手続きがまだ途中でも相談できるかどうかは<a href="/guide/soudan-shiteii-joutai-checklist">相続した家、まだ相談していい？7つの状態別チェック</a>で整理しています。

## 契約に進む前に、契約書で確かめたいこと

検討の結果、売却に進む場合も、契約書に署名する前に次の点を確認してください。

- <strong>売買代金</strong>：提示額から変わっている場合は、変わった理由
- <strong>引渡しの時期と、引渡しのときの状態</strong>：荷物を残してよいか、入居者がいる状態か
- <strong>費用の負担</strong>：測量・解体・荷物の処分などを誰が負担するか
- <strong>引渡し後の不具合の扱い</strong>：売主がどこまで責任を負うか
- <strong>手付金の扱い</strong>：民法では、買主が手付を交付した場合、相手方が契約の履行に着手するまでは、買主は手付を放棄し、売主は手付の倍額を現実に提供して、契約を解除できると定められています（第557条）。契約書で別の定めがあるかも確認してください

契約から決済までの流れと必要書類は<a href="/guide/wakeari-bukken-kaitori-tetsuzuki">訳あり物件の買取手続き｜必要書類・告知書の書き方</a>にまとめています。売却にかかる税金は税理士、登記の手続きは司法書士にご確認ください。

## よくあるご質問

<strong>Q. 提示された査定額は、そのまま売却価格になりますか？</strong>
そのまま確定するわけではありません。売買の代金が決まるのは、売主と買主が合意して契約を結んだときです。机上の見当なのか、現地を確認したあとの提示なのかで、あとから動く可能性も変わります。まず、どの段階の数字かを確認してください。

<strong>Q. 提示額を受け取ったら、すぐに返事をしなければいけませんか？</strong>
相談・査定を受けたからといって、その場で売却を決める必要はありません。ただし、提示額に有効期限が設けられている場合もあります。検討を始めるときに、いつまでに返事が必要か、期限を過ぎたらどうなるかを確認しておくと安心です。

<strong>Q. 査定のときに伝えていなかったことがあります。今から伝えても大丈夫ですか？</strong>
検討中に伝えてください。入居状況が変わった、建物の不具合に気づいた、資料が見つかったなど、提示の前提になった情報が変わると金額や条件が見直されることがあります。見直しの結果が上がるか下がるかは内容しだいです。契約後に伝えるより、検討中に伝えるほうが条件を整理しやすくなります。

<strong>Q. 他社の提示額と比べるとき、何をそろえればよいですか？</strong>
金額だけでなく、残っている荷物の処分・測量・解体などの費用を誰が負担するか、引渡しの時期、引渡し後の不具合の責任をどう扱うかをそろえて比べてください。提示額が同じでも、売主が負担する費用が違えば手元に残る金額は変わります。

## まとめ

- 提示額を受け取っても、<strong>その場で返事をする必要はありません</strong>。まず、どの段階の数字か、有効期限はいつまでかを確認します。
- 検討中は、<strong>荷物の扱い・費用の負担・入居者の扱い・引渡し後の不具合の扱い・引渡し時期</strong>など、金額の前提を確かめます。
- 査定を頼んだときに伝えた内容と<strong>今わかっていること</strong>にずれがあれば、検討中に伝えます。
- 期限と、決めるために<strong>同意が必要な人</strong>を整理してから判断します。
