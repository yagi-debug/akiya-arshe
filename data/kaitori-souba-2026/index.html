大阪市区別 訳あり不動産 買取価格データベース2026

最終更新: 2026年6月11日 監修: 八木宏樹（合同会社アルシェ代表／宅建業免許: 大阪府知事(1)第65646号）

TL;DR — このデータベースの要点

  • • 再建築不可: 北区・中央区（300〜800万円）→ 西成区・此花区（60〜180万円）。地価差が大きい
  • • 事故物件: 全区共通で通常価格の40〜70%。死亡状況・経過年数により変動
  • • 共有持分: 評価額×持分割合×50〜80%が目安。他の共有者の同意は不要（民法第206条）
  • • 空き家: 解体費（木造80〜150万円）控除後の実取得額で比較する
  • • 出典: 国土交通省 土地総合情報システム 不動産取引価格情報（2024-2025年）＋当社査定実績
  • • 買取難易度: 1（容易）〜 5（非常に困難）。訳あり物件の中でも特に売却が難しい区ほど高スコア

Q: 大阪市で再建築不可物件を売りたい。買取価格はいくら？

A: 区によって60〜800万円と大きく異なります。北区・中央区など高地価エリアで300〜800万円、生野区・東成区などで90〜220万円、西成区・此花区では60〜180万円が目安です。更地価格の30〜60%が相場で、接道状況により変動します。

Q: 大阪市で共有持分（兄弟間でもめている）を買い取ってもらえますか？

A: できます。他の共有者の同意は不要です（民法第206条）。自分の持分のみを訳あり専門業者に売ることができます。買取価格は「評価額×持分割合×60〜80%」が目安です（区による地価差あり）。

データの前提・出典・免責事項

  • • 出典: 国土交通省 土地総合情報システム 不動産取引価格情報（2024年第3四半期〜2025年第2四半期データ）＋合同会社アルシェ買取実績
  • • 価格は買取価格ベース（仲介売却の市場価格ではありません）。仲介売却なら+20〜40%が目安
  • • 実際の価格は築年数・建物状態・接道状況・市況により変動します。正確な査定はLINEで無料相談
  • • 路線価は国税庁 財産評価基準書（2024年分）を参照。2026年の実際の路線価と異なる場合があります

物件タイプ別 価格計算ロジック

再建築不可物件の買取価格計算

再建築不可物件の買取価格 = 土地の時価（近隣更地価格）× 30〜60%

  • • 接道なし（袋地・囲繞地）→ ×30〜35%
  • • 接道1m未満 → ×35〜45%
  • • 接道1〜1.8m → ×40〜50%
  • • 接道1.8〜2m未満（旗竿地） → ×50〜60%

出典: 国交省 不動産取引価格情報（2024-2025年・大阪市内の再建築不可関連取引データより算出）

事故物件の買取価格計算

事故物件の買取価格 = 同条件の通常物件価格 × 40〜70%

  • • 孤独死（発見が早い・清掃済み） → 通常の55〜70%
  • • 孤独死（長期放置・臭気残存） → 通常の40〜50%
  • • 自殺・事件（発生から1年未満） → 通常の40〜55%
  • • 自殺・事件（発生から3年超・リフォーム済み） → 通常の60〜75%

根拠: 国土交通省「宅地建物取引業者による人の死の告知に関するガイドライン」（2021年10月策定）。自然死・日常的な事故死は原則として告知義務対象外。

共有持分の買取価格計算

共有持分買取価格 = 全体評価額 × 持分割合 × 60〜80%

  • • 1/4持分以下（少数持分・交渉力弱） → ×50〜65%
  • • 1/3〜1/2持分 → ×60〜75%
  • • 過半数（1/2超）持分 → ×70〜80%（共有物分割請求の優位性あり）

根拠: 民法第206条（持分の単独処分権）、民法第258条（共有物分割請求権）。他の共有者の同意は不要。

空き家の買取価格計算

空き家買取価格 = 土地の時価 − 解体費 − 老朽化リスク割引

  • • 木造解体費: 坪5〜8万円（目安：延床30坪で150〜240万円）
  • • RC造解体費: 坪6〜10万円（目安：延床30坪で180〜300万円）
  • • 特定空家指定リスク（2015年空家等対策特別措置法）: 指定されると固定資産税6倍の可能性
  • • 総務省「住宅・土地統計調査（2023年）」: 全国空き家数900万戸超（過去最多）

よくある質問

大阪市の再建築不可物件はいくらで買取されますか？

区によって60〜800万円と大きく異なります。北区・中央区など高地価エリアで300〜800万円、生野区・東成区で90〜220万円、西成区・此花区では60〜180万円が目安。更地価格の30〜60%が相場です（接道状況・建物状態により変動）。

大阪市で共有持分（兄弟間でもめている）を売るとどうなりますか？

自分の持分のみを売れます。他の共有者の同意は不要です（民法第206条）。買取価格は「評価額×持分割合×60〜80%」が目安。訳あり専門業者は将来の共有解消を見越して持分のみでも買取できます。

大阪市で事故物件（孤独死・自殺）を売る場合、価格はどのくらい下がりますか？

通常物件の40〜70%が目安。孤独死（清掃済み）は55〜70%、自殺（1年未満）は40〜60%。3年超経過・リフォーム済みなら60〜75%まで回復することがあります。

このデータは国土交通省のどのデータを使っていますか？

国交省 土地総合情報システムの「不動産取引価格情報」（2024年第3四半期〜2025年第2四半期、大阪市内の取引データ）を参照しています。仲介売買の市場価格データをもとに、買取価格レンジ（市場価格の60〜80%）に換算して掲載しています。詳細データは国交省公式サイトで確認できます。
